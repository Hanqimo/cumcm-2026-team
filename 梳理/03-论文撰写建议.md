# 第一部分 · 问题1

## 一、写作顺序（建议）

针对问题1部分，按以下逻辑顺序展开，公式与数值分别有唯一来源：

1. **有界误差 + 正向角域**：交代为什么用集合可行域而不是概率模型（题面只给误差界、同点误差固定）。
2. **区域构造与顶点直径**：半平面交表示 → 区域状态分类 → 顶点直径公式及证明。
3. **可实现的反例与圆覆盖判定**：先证明"该多边形确实由合法角域构造"，再算直径与最小包围圆。
4. **20 米清除条件**：`R(P) ≤ 20` 的充要判定，与 `D ≤ 40` 的区分。
5. **保守计算与验证**：数值容差、ε=1.005° 敏感性、260 项检查与独立核验。

## 二、正文必须写清楚的 5 个要点

1. **为什么是有界误差集合**：明确写出"题设仅给出 `[−1°,+1°]` 误差界、同一地点重复检测误差固定、未给概率分布"，因此不假设零均值/均匀/高斯、不假设不同地点误差独立，改用最坏情况可行域。这是模型成立的前提，也是评审最看重的"建模依据"。

2. **为什么用叉积半平面而不是斜率式**：说明 `tan θ` 在 90°/270°、0°/360° 跨界处有奇异性，而方向向量叉积表示 `[u(θ±ε), x−s_i]` 全方向一致、且自然排除反向扇区。

3. **直径顶点公式的证明**：凸组合 + 三角不等式，两行即可，但**必须完整写出**，不要只给结论。

4. **反例要先证"可实现"再给结论**：写反例时不能只画一个三角形就说"直径圆不能覆盖"。要按 v01 的论证——三个检测点 `s_i = v_i − 1000·e_i`、示向度 `θ_i = arg(e_i)+1°`——说明三条下边界半平面交集恰好是这个三角形，再给 `D=38, R=38/√3≈21.94`。这样反例才属于本题测向机制，而不是随意多边形。

5. **`D ≤ 40` 与 `R ≤ 20` 的区别**：这是第一问最容易被误解、也是最有价值的一条结论，建议单独成段强调"直径 ≤40 米只是必要非充分，最小包围圆半径 ≤20 米才是保证清除的充要条件"，并说明它如何被问题2/3 复用。

## 四、必须保留的限定（不能写成"已完成"）

写作时要守住以下边界，避免过度声称：

- **状态**：问题1 的 v01/v02 均为"研究分支推荐"，`adopted.md` 尚未登记为团队正式采用——但**论文正文不必写这个内部状态**，只需确保"模型 + 保证条件"本身严谨。
- **纯角域 vs 物理区域**：问题1 的多边形是"纯测角交会区域 P"；叠加 1800 米圆域后含圆弧边，**必须分别命名**（如 `P` 与 `P_phys = P ∩ Ω`），不能混称。
- **保证成立的前提**：`R(P) ≤ 20 ⇒ 可保证清除` 依赖"可行域确实包含真实目标"这一前提；浮点计算不是区间算术证明。
- **数值结果性质**：所有数值例子均为**合成验证**，不是官方模拟器成绩；`4.55e-13`/`5.96e-10` 是"这批验证集上的数值差"，不是任意输入的误差上界。
- **不得写成已完成**：问题3/4 全搜索策略、官方演练成绩、连续优化的全局最优证明、"两次观测就能保证清除"等都不属于第一问结论。

# 第二部分 · 问题2

> 依据 `contest/paper/notes/q12-v1-writing-handoff.md`（前两问写作交接）整理，并结合问题2 已有成果归纳。

## 一、写作顺序（问题2 部分）

1. **第二点必须保持可接收**：交代为什么选第二点多了"保证接收"这个新约束（全向源 1000–1500 米，第二点超出半径就拿不到示向度）。
2. **R≥r 关键关系**：从"首次已收到信号"推出 R≥r，说明不能一边假设目标远在 1500 米一边把接收半径固定为 1000 米。
3. **三圆盘候选域及证明**：三圆盘交集 K、局部坐标表达式、两种情形的保证接收证明。
4. **预算约束下的 minimax 选点**：C(B,h)、决策模型 F(q)、45° 基线。
5. **保守计算与验证**：圆域外包、读数分箱外包 U(q)、四预算结果、1305 项检查与 V02 独立核验。

## 二、正文必须写清楚的 5 个要点

1. **为什么要"先保证接收，再优化定位"**：纯横移可能丢信号（1118 米反例），交会几何好看却拿不到第二个示向度；三圆盘域正是把"能收到"变成几何约束。
2. **R≥r 的推导**：已测到距离 r 的源必然 R≥r，这是问题2 区别于问题1 的新关系，也是三圆盘域比"q 到 P₁ 所有点 ≤1000 米"更不保守的原因。
3. **三圆盘域的证明要完整写**：分 0≤r≤R₀ 与 R₀≤r≤1500 两种情形，用范数凸性和代数不等式，不要只给结论。
4. **90° 最优是错误直觉**：线性近似下 90° 最优，但移动改变 r₂ 与 β、r₁ 未知，不能推出"绕真目标 90°"可执行最优；引用 L06/L07 说明最优交会角依赖误差模型。
5. **读数分箱 ≠ 采样**：必须写清"扩大角域的外包关系"（Q2-13），否则"连续最坏值"会被质疑；750 米预算下改进极小，如实交代，不夸大复杂搜索收益。
