## 一句话结论（问题1）

问题1要求：①给出交会定位法下多边形定位区域直径的算法；②判断"以定位区域直径为直径的圆能否覆盖该区域"。

- **直径算法**：把每次示向度观测写成"正向角域"（两个半平面的交集），多次观测取交得到定位区域 `P = ∩W_i = {x : Ax ≤ b}`；区域直径等于**最远顶点对距离**，即 `D(P) = max_{i,j} ‖v_i − v_j‖`。
- **能否覆盖**：**不一定**。最小包围圆半径 `R(P)` 满足 `R ≥ D/2`，只有 `R = D/2` 时直径圆才能覆盖。边长 38 米的等边三角形反例中 `D = 38` 米，而 `R = 38/√3 ≈ 21.94` 米，直径圆（半径 19 米）无法覆盖该区域。
- **对后问的关键传递**：`D ≤ 40` 只是保证清除（光学清除半径 20 米）的**必要非充分**条件；正确判据是 `R(P) ≤ 20`。

## 一句话结论（问题2）

问题2要求：①给出第二个检测点的选择策略（以获得较好定位效果）；②给出第二个检测点的候选区域。

- **候选区域**：三圆盘交集 `K = B̄(s,R₀) ∩ B̄(s+R₀·u(θ−ε), R₀) ∩ B̄(s+R₀·u(θ+ε), R₀)`（`R₀ = 1000` 米），局部坐标 `a²+b² ≤ R₀²` 且 `a²+b² ≤ 2R₀(a·cosε − |b|·sinε)`。这是保证第二点**仍能收到信号**的充分区域，其证明利用了"首次已接收 ⇒ R ≥ r"这一关键关系。
- **选点策略**：在移动预算 `B` 与横向分离阈值 `h` 约束的候选域 `C(B,h)` 内，最小化第二次观测后可行域的**最坏最小包围圆半径**（minimax，无概率分布假设）。
- **数值结果**：预算 250/500/750/1000 米对应最坏后验半径上界 `U ≈ 220.0 / 123.9 / 81.4 / 56.2` 米；750 米预算下与 45° 基线（81.48）几乎无差，不能夸大复杂搜索的收益。
- **对后问的关键传递**：全向接收保证依赖"全向源 + 首次已接收"，不能移植到第四问定向源；"只加一次观测就保证清除"不被保证。
