## 基线究竟来自哪里

Vander Hook、Tokekar、Isler，*Cautious Greedy Strategy for Bearing-only Active Localization: Analysis and Field Experiments*，JFR 2014，31(2):296–318，[DOI](https://doi.org/10.1002/rob.21499)，重点为第6.1节Algorithm 1。该文在第8节数值界讨论中使用β=0.1；本次在评估前固定这一值，未按测试结果调参。

保留“协方差最大主轴的法向、随不确定性收缩的站距、两侧择近”的选点结构。原文使用高斯与EKF并处理方位歧义；本次以有界角域的均匀面积矩代替均值协方差，谨慎参数记为β_c，避免与全局第二问的首次方位β混淆。站距按原文公式由最大标准差与β_c计算，角噪声尺度取1°/√3仅用于该选点代理；不存在将此代理作为真实高斯模型或性能保证的主张。

候选若超出保证接收范围，沿同一法向缩至整个区域均在999.9米内；重复位置用原有安全侧移点回退。可靠清除半径19.5米。搜索采用原点与1200米圆周六点，先按移动距离加0.15倍区域半径选择已知目标，逐源完成；无待处理目标时按(距离+100米)/覆盖增益选择扫描点。清除后不强制返回。两种策略共用整单元逐频道覆盖停止标准，基线没有引入v6的联合负观测、整体服务路由、途中补测和提前试清。

这是事后补充验证的**文献思路适配基线**，不是原论文完整复现，也不是声称团队早期已测过这个版本。文献05继续作为多目标联合安排的启发，不使用其论文实验数字充当本题成绩。

## 复算与归档

在本目录运行 `python -X utf8 analyze.py` 可从逐场数据重算统计，运行 `python -X utf8 replot.py` 可重绘两张比较图。依赖numpy、scipy、matplotlib；绘图默认Microsoft YaHei字体。analyze.py复算数值，不冒充再次核验未分发的官方原始日志。

official/保存30场新演练结果、统计及既有v4/v6数据；原始官方jlog仍存本地official-batch目录，未改写也未公开上传。每份的原名与SHA-256留在结果表，30份已逐一核验。baseline/保存冻结适配代码；evaluation_protocol.json记录演练前的分析计划。paired/含两组清单、全部30场结果与fixtures，以及代表场景完整动作。

新实验只通过指定的统一默认入口run_local.py开展；没有复制或另建默认模拟器。实际调用、模拟器配置及策略哈希见paired/*/manifest.json。基线可用该入口的`--strategy-dir`加载。历史正式归档保持原样，版本归属仍按照此前用户更正及正文说明处理。
