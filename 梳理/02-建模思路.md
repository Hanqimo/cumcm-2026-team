# 第一部分 · 问题1

## 0. 题目要求（原话）

> **问题1** 已知若干个检测点坐标及某干扰源关于这些检测点的示向度，请给出采用交会定位法（见附录2）计算多边形定位区域直径（即区域内任意两点之间距离的最大值）的算法。以定位区域直径为直径的圆能否覆盖此定位区域？

题目实际问两件事：
1. **算法**：如何计算交会定位所得"多边形定位区域"的直径；
2. **判定**：以该直径为直径的圆，能否覆盖这个定位区域（答案是**不一定**，这是本题的核心考点）。

## 1. 问题分析：确定建模范式

题目只给了误差界（示向度误差在 `[−1°, +1°]` 内，且**同一检测点误差固定**、不随时间变化），**没有给任何概率分布**。因此：

- 不能用高斯/协方差椭圆、卡尔曼滤波等**统计模型**——它们需要题面未给的分布与独立性假设。
- 应采用**有界误差（bounded-error / set-membership）可行域范式**：把每一次观测解释为"真实目标必定落在某个集合内"，多次观测取交集，得到"最坏情况下的可行区域"。

这决定了整个第一问（以及向后续小问传递的保证）都建立在**集合几何**而非概率之上。

## 2. 单次观测 → 正向角域（wedge）

记检测点为 `s_i = (s_ix, s_iy)`，示向度读数为 `θ_i`（度），误差界 `ε = 1°`（推导时转弧度 `ε = π/180`）。

一次观测不是一条精确射线，而是一个**正向（前向）扇形区域** `W_i`：真实目标位于以 `s_i` 为顶点、方向从 `θ_i−ε` 到 `θ_i+ε` 的扇形内，且**排除 `s_i` 背后的反向扇区**（因为示向度指向目标方向）。

为避免 `tan θ` 在 90°/270° 附近的奇异性，用**方向向量的叉积**把每个角域写成两个半平面的交集：

```
W_i = { x : [u(θ_i−ε), x−s_i] ≥ 0,   [u(θ_i+ε), x−s_i] ≤ 0 }      (Q1-1)
```

其中 `u(α)=(cos α, sin α)`，`[a,b]=a_x b_y − a_y b_x` 为二维叉积。写成标准不等式 `Ax ≤ b`：

```
[ u_iy⁻  −u_ix⁻ ]          [ u_iy⁻  −u_ix⁻ ]
[ −u_iy⁺  u_ix⁺ ]  · x  ≤  [ −u_iy⁺  u_ix⁺ ] · s_i              (Q1-2)
```

若所有读数符合题设，真实目标 `g` 属于每一个 `W_i`，从而属于它们的交集。

## 3. 交会定位区域 P（半平面交）

```
P = ∩_i W_i = { x : A x ≤ b }
```

`P` 是**闭凸多面集**，但不保证有界。只有一次观测、或交会几何不足时，`P` 会延伸到无穷远。区域状态分五类：

| 状态 | 含义 | 处理 |
|---|---|---|
| empty | 观测互相矛盾（频道误关联/角度单位错/舍入） | 必须上报，**不能**靠丢弃"最不方便"的观测强行恢复非空 |
| unbounded | 只有单方向/几何不足 | 直径记为 ∞，不能加"任意大盒子"裁剪掩盖无界 |
| point / segment | 退化 | 单独保留退化表示 |
| polygon | 正常有界多边形 | 进入顶点/直径/包围圆计算 |

## 4. 算法 A01：区域求解与顶点枚举

1. 归一化半平面法向量；解可行性线性规划（LP），不可行 → `empty`。
2. 在 `P` 上分别最大化 `x, −x, y, −y` 四个方向：任一方向无界 → `unbounded`；四个方向都有界 → 有界。（这个判断**不需要**任意大盒子。）
3. 取一个可行点做坐标平移，减轻大坐标下的数值相消。
4. 枚举所有不平行边界直线的交点，只保留满足全部半平面约束的点，按容差去重 → 顶点集 `{v_1,…,v_h}`。
5. 对二维区域按极角整理顶点顺序；点/线段保留退化表示。
6. 输出最大约束残差（诊断用），计算直径与最小包围圆。

复杂度：`m = 2n` 条约束，交点枚举 + 可行性检验 `O(m³)`，顶点存储 `O(h)`。小规模用"容易审查的枚举"；观测很多时再换半平面交 `O(m log m)` 与旋转卡壳。

## 5. 直径：只需算顶点对

```
D(P) = max_{x,y∈P} ‖x−y‖ = max_{i,j} ‖v_i − v_j‖                       (Q1-3)
```

**证明**：把任意两点写成顶点的凸组合 `x=Σα_i v_i`、`y=Σβ_j v_j`，由三角不等式

```
‖x−y‖ = ‖Σ_{i,j} α_i β_j (v_i − v_j)‖ ≤ Σ_{i,j} α_i β_j ‖v_i−v_j‖ ≤ max_{i,j} ‖v_i−v_j‖
```

顶点本身属于 P，故上界可达到。因此直径只需枚举 `h(h−1)/2` 个顶点对，复杂度 `O(h²)`。点区域直径为 0，线段区域直径为两端点距离。

## 6. 核心问题：直径圆能否覆盖区域？

定义最小包围圆半径：

```
R(P) = min_c max_{x∈P} ‖x−c‖ = min_c max_i ‖v_i−c‖                        (Q1-4)
```

任意覆盖 P 的圆都满足 `R ≥ D/2`；**存在直径恰为 D 的覆盖圆 ⟺ R = D/2**。

**直接判定方法**（不必先求最小圆）：任取一个最远点对 `a, b`。若半径 `D/2` 的圆包含 `a, b`，则由 `D = ‖a−b‖ ≤ ‖a−c‖+‖b−c‖ ≤ D` 推出所有不等式取等，必有 `c = (a+b)/2`。于是只需检查所有顶点到中点 `(a+b)/2` 的距离是否 `≤ D/2`；若失败，换其他圆心也无法挽救。

### 反例：边长 38 米的等边三角形（本题可实现的真实反例）

取等边三角形 `T`，`v₁=(0,0)`，`v₂=(38,0)`，`v₃=(19, 19√3)`。令三个检测点 `s_i = v_i − 1000·e_i`（`e_i` 为逆时针边方向单位向量），示向度 `θ_i = arg(e_i) + 1°`，误差界仍 `±1°`。

- 每个角域的下边界正好沿三角形一条边（保留该边内侧），上边界向内旋转 2°；
- 由于第三顶点相对检测点的偏角 `arctan(19√3/1019) < 2°`，上边界约束对整个 T 冗余；
- 因此三条下边界半平面的交集**恰好是 T**——这个三角形确实可由本题的三个 2° 测向角域构造出来（不是随便选一个无法实现的多边形）。

取三角形重心为真实源，三次示向度均符合 ±1° 误差、源到各检测点 < 1500 米、源在 1800 米圆域内，满足全部物理条件。

```
D(T) = 38 米，  R(T) = 38/√3 ≈ 21.9393 米 > 19 米 = D/2             (Q1-5)
```

**结论：直径 38 米的圆（半径 19 米）不能覆盖 T，甚至连直径 40 米的圆也无法覆盖。** 所以"以定位区域直径为直径的圆能否覆盖"的答案是**不一定**。

### 最小包围圆的计算

最小圆由**两个直径端点**或**三个非共线边界点**决定（Welzl，L11）。实现：先检查最远点对的直径圆能否覆盖；不能则枚举三点外接圆，保留能包含全部顶点的最小者，最坏 `O(h⁴)`。平面中还有 `D/2 ≤ R ≤ D/√3` 的界（仅作核验，不代替实际计算）。

## 7. 向后续小问传递的清除判据

光学清除半径 20 米（工程实现取 `ρ = 19.5` 米）。若 `P` 确实包含真实目标，则：

- 从位置 `q` 保证清除 ⟺ `max_i ‖v_i − q‖ ≤ 20`（即 q 到每个顶点都不超过 20 米）；(Q1-6)
- 全部保证清除位置 = `C(P) = ∩_i B̄(v_i, 20)`（各顶点 20 米闭圆盘的交）；(Q1-7)
- 存在至少一个保证清除位置 ⟺ `R(P) ≤ 20`（最小包围圆半径不超过 20 米）。

**关键区分**（这是第一问对后问最有价值的一条）：

- `D ≤ 40` 只是**必要条件，不充分**；
- `R ≤ 20` 才是**充要条件**；
- `D ≤ 20√3` 是充分条件，但不如直接算 R 精确。

## 8. v02 补充：最近的保证清除位置（问题3 的接口）

既然能保证清除，机器人还要走到哪里？在 v01 基础上求从当前位置 `p` 到清除可行集 `K_ρ` 的欧氏投影：

```
K_ρ = { q : max_{x∈P} ‖q−x‖ ≤ ρ } = ∩_i B̄(v_i, ρ)，  ρ = 19.5
q* = argmin_{q∈K_ρ} ‖q − p‖
```

- 若 `p ∈ K_ρ`，原地清除；
- 否则最优点在边界：要么是单个圆盘上朝 `p` 的**径向投影**，要么是**两个圆盘的交点**。
- 算法：枚举每个顶点圆的径向投影 + 每对圆的交点，逐个检验所有圆盘约束，取离 `p` 最近的可行点。实数精确运算下该枚举给全局最近点；数值上以最小包围圆圆心作后备（后备只保证可行，不声称最优）。复杂度 `O(m³)`。

## 9. 数值与舍入边界（写作时必须交代）

- 主模型 `ε = 1°`；因题面未明确"±1° 是对舍入前还是舍入后"，另设 `ε = 1.005°` 的工程保守选项（覆盖"先 ±1° 误差再四舍五入到 0.01°"）。
- 半平面法向量归一化后按米衡量残差；几何容差约 `1e-7` 米，近似平行判定 `1e-12`，清除标记预留 `1e-6` 米。
- **浮点程序不是区间算术证明**：对极端病态输入必须检查状态与残差。
- 同位置重复检测得到相同约束，**不能**靠重复次数把 ε 除以 √N（误差固定而非独立）。

## 10. 验证（R003，已通过）

- **260 项检查**：3500 个直接 `atan2` 角度判断、60 组多站随机一致观测、解析特例、空集/无界/点/线段退化、平移旋转不变性、新增观测的区域单调性。
- **独立交叉核验**：用 LP 支持函数核对枚举顶点，用缩放后的凸范数优化核对最小包围圆。最大支持值差约 `4.55e-13` 米，包围圆半径差约 `5.96e-10` 米。
- v02 补充另有 **200 例独立凸投影核验**（SLSQP），目标距离最大差 `3.25e-7` 米；相对旧"包围圆圆心—机器人"线段方法平均少走 `0.7704` 米。

## 11. 建模思路小结（论文主线）

```
示向度观测(θ_i, ±1°误差) ──► 正向角域 W_i（两个半平面）
        │ 多次观测取交
        ▼
定位区域 P = ∩W_i = {x:Ax≤b}（闭凸多面集，可能无界）
        │ 顶点枚举(半平面交)
        ▼
直径 D(P) = 最远顶点对距离  ──►  最小包围圆半径 R(P)
        │                                    │
        │ 反例：38m等边三角形 D=38, R≈21.94   │
        ▼                                    ▼
「以 D 为直径的圆不一定覆盖」         清除判据：R(P)≤20 ⟺ 存在保证清除点
```

核心创新点/亮点（可直接写进论文"本文工作"）：
1. 全方向统一的**叉积半平面**表示（不引入 tan 奇异性）；
2. 顶点直径证明 + 最远点对中点的同直径圆判定；
3. 由三个 2° 角域**真实构造**的等边三角形反例（证明 D≤40 不充分）；
4. 从 20 米光学清除条件推出**保证清除位置集合 = 顶点圆盘交**。

# 第二部分 · 问题2

## 0. 题目要求（原话）

> **问题2** 已知某全向干扰源在一个检测点处测得的示向度，给出第二个检测点的选择策略，以获得关于该干扰源较好的定位效果，并给出第二个检测点的候选区域。

题目实际问三件事：
1. **选点策略**：第二个检测点选在哪；
2. **候选区域**：如何保证第二点还能收到信号（这是问题1 没有的新约束）；
3. **评价指标**：什么叫"较好的定位效果"。

## 1. 问题分析：从"定位"到"保证接收 + 主动选点"

问题1 只关心给定若干观测后如何算定位区域；问题2 关心**主动选点**——已有第一次观测，要主动选第二个检测点。这里多了一个问题1 没有的硬约束：**第二点必须还在干扰源的有效接收半径内**，否则拿不到第二次示向度。

关键事实链（问题2 的核心）：

- 全向源接收半径 `1000 ≤ R ≤ 1500`；
- 首次已返回有效示向度 ⇒ `5 < r = ‖g−s‖ ≤ R`（距离 ≤5 米会返回"过强"而非示向度）；
- 因此 **`R ≥ r`**：已测到距离 r 的源，其接收半径 R 一定 ≥ r。这是问题2 最重要的隐藏关系，是三圆盘候选域的基础。

## 2. 已知量与评价标准

- 已知：`s`、`θ`；未知：`g`、`r = ‖g−s‖`、`R`。
- 状态可行集（精确）`Z₁ = {(g,R) : g∈Ω∩W(s,θ), 5<‖g−s‖≤R, 1000≤R≤1500}` (Q2-1)。
- 后验凸外包 `P₁ = Ω ∩ W(s,θ) ∩ B̄(s,1500)` (Q2-2)，省略 5 米内孔（保守，不删真目标）。
- **评价指标**：最小化第二次观测后可行域的**最坏最小包围圆半径**，而非面积——面积小但狭长的区域仍可能无法被 20 米清除圆覆盖。不用概率先验。

## 3. 三圆盘保证接收候选域 K

第二点 `q = s + a·u + b·v`（`u = u(θ)`，`v` 为 u 逆时针转 90°）。取 `R₀ = 1000` 米：

```
K = B̄(s,R₀) ∩ B̄(s+R₀·u(θ−ε), R₀) ∩ B̄(s+R₀·u(θ+ε), R₀)          (Q2-3)
```

局部坐标表达式：

```
a² + b² ≤ R₀²，   a² + b² ≤ 2R₀(a·cosε − |b|·sinε)               (Q2-4)
```

K 关于首次示向度轴对称，无需知道真实目标距离或朝向，也不要求 q 落在目标圆域内。

**保证接收的证明（Q2-5）**：令 s=0、θ=0，真源 g=r·u(φ)，|φ|≤ε。首次接收 ⇒ R≥max(R₀,r)。由三圆盘约束得 `‖q‖² ≤ 2R₀·q·u(φ)`（只需检查扇区端点，区间内部驻点只给更大投影）。

- 情形一 `0≤r≤R₀`：g 在 0 与 R₀·u(φ) 的线段上，两端点到 q 距离都 ≤R₀，由范数凸性 `‖q−g‖ ≤ R₀ ≤ R`；
- 情形二 `R₀≤r≤1500`：`‖q−r·u(φ)‖² − r² = ‖q‖² − 2r·q·u(φ) ≤ ‖q‖² − 2R₀·q·u(φ) ≤ 0`。

两种情况都保证第二点收到信号。

**反例（为什么单纯横移不可靠）**：s=(0,0)、θ=0°、真源 g=(1000,0)、R=1000。横移至 q=(0,500) 时距离 √1250000 ≈ 1118 米 > 1000，第二点无信号。反过来，"q 到 P₁ 所有点 ≤1000 米"又忽略 R≥r 而过度保守；Q2-3 正是利用这条关系给出更有用的安全区域。

## 4. 排除退化观测 C(B,h)

沿示向度轴移动可能仍与目标共线（目标距离未知时不能保证走到侧面）。设 B 为移动预算、h 为横向分离阈值：

```
C(B,h) = {s+au+bv : (a,b)∈K, a²+b²≤B², |b|cosε − a·sinε ≥ h}    (Q2-6)
```

对扇区内任意方向 u(φ)，交会角 β 满足 `|sinβ| ≥ h/1500` (Q2-7)，保证不与两检测点完全共线。h>5 排除 near 分支。本轮取 h=20 米（设计参数，与清除半径同值但机制不同）。

**45° 基线**（Q2-8）：`q₄₅ = s + (B/√2)(u±v)`，ε=1°、B≤1000 时满足 K，可解释、易执行。

## 5. 决策模型（minimax）

第二次读数 ψ 后更新 `P₂(q,ψ) = P₁ ∩ W(q,ψ)` (Q2-9)。定义：

```
F(q) = sup_{ψ∈Ψ(q)} R(P₂(q,ψ))，   q_B* ∈ argmin_{q∈C(B,h)} F(q)   (Q2-10)
```

这是对未知真目标、未知第二次误差的**最坏读数**评价，无需概率分布。质量子区域 `C_η(B,h) = {q∈C : F(q)≤η}` (Q2-11)。

题目未给移动成本-精度权重，故给 B=250/500/750/1000 的策略族，不强行定唯一最优。虚拟时间 `‖q−s‖/5 + 5` 秒。

## 6. 线性近似与"90° 最优"的错误直觉

局部线性化误差带下，平行四边形最大中心偏差：

```
R_lin = ε·√(r₁²+r₂²+2r₁r₂|cosβ|) / |sinβ|                          (Q2-12)
```

固定 r₁、r₂ 时 β=90° 最小。但移动 q 会同时改变 r₂ 和 β，r₁ 又未知，**不能**推出"绕真目标 90°"是可执行最优策略（L06/L07 也指出最优交会角依赖误差模型）。该式仅用于解释/筛选，不承担最坏误差保证。

## 7. 数值算法与保证层次

1. **圆域保守外包**：半径 r 的圆盘 → N 条切线外接正 N 边形（径向差 r(sec(π/N)−1)，N=360 时 1500 米圆约 0.0571 米）。
2. **读数分箱必须扩大角域**：不能只采样有限 ψ 就称连续最坏值。覆盖区间 I_j，中点 m_j、半宽 δ_j，有 `W(q,ψ;ε) ⊆ W(q,m_j;ε+δ_j)`，故 `U(q) = max_j R(P̄_{2j}) ≥ F(q)` (Q2-13)。
3. **第二点搜索**：极坐标候选枚举 → 0.5° 粗筛（166 点）→ 0.2° 加密 → 0.05° 重排入围 6 点 + 45° 基线。
4. 输出第二点、候选域余量、最坏读数包络、U、耗时、敏感性；候选域为空则报诊断，不悄悄退回可能丢信号的点。

复杂度约 `O(MJH⁴)`（M 候选点、J 读数箱、H 后验顶点）。

## 10. v02 补充：结合当前定位区域的接收判定

第三问已有多约束状态时，用 P（当前凸外包）+ s（首次正观测）+ q（拟议测点）判定是否保证接收。固定 R 未知但 R≥R₀ 且 R≥‖x−s‖：

```
F(q) = max_{x∈P} [ ‖x−q‖² − max{R₀², ‖x−s‖²} ] ≤ 0
```

有限枚举：P 顶点 + 边与圆交点 + 反径点 `x* = s − R₀(q−s)/‖q−s‖`，取最大目标值。接口 `reception_violation` 返回最大平方违约量与证据点。第三问在 `F(q) ≤ −0.01 m²` 时放行。

## 11. 建模思路小结（论文主线）

```
首次观测(s,θ) ──► 可行集 Z₁（含 R≥r）──► 凸外包 P₁
                        │
                        ▼
三圆盘候选域 K（保证接收）──► C(B,h)（预算+横向分离，排除共线退化）
                        │
                        ▼
minimax：min_q max_ψ R(P₂(q,ψ)) ──► 四预算推荐点
                        │
                        ▼
读数分箱外包 U(q) ≥ F(q)（连续读数保证）
```

核心创新点/亮点（可直接写进论文"本文工作"）：
1. 利用"首次已接收 ⇒ R≥r"证明**三圆盘交集保证接收**（反对无条件 90° 与单纯横移）；
2. 横向分离约束排除未知目标下的共线退化；
3. 读数分箱扩大角域，把有限采样升级为**连续读数外包保证**；
4. 预算-精度曲线而非强行加权唯一最优。
