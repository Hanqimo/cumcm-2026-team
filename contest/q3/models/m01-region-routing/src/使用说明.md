# 问题三改进演练策略 v2

推荐运行位置：`D:\math modeling\正式题目工作区\B-simulator\improved-p3`。

1. 双击 `run_practice.cmd`。程序自动复用旁边 `simple-strategy/config.json` 的队号和端口。
2. 在模拟器选择“问题3演练测试”，开始并等到接口就绪、等待机器狗进入。
3. 回到程序窗口按 Enter。程序自动进入、扫描、定位、清除和退出，不能同时运行旧策略。
4. 结束后保留模拟器结果及案例编码，导出官方 `.jlog`。本策略记录位于自身 `runs/时间戳-编号/`。

只检查环境：双击 `check_setup.cmd`；它不会连接模拟器。也可以在本目录执行 `python run_robot.py --check`。

程序按问题三全向干扰源设计，不能用于问题四。API 不能识别界面选的是演练还是正式，按 Enter 前请选好本轮要运行的演练。

## 相比旧策略

- 保留每个频道的测向历史，用多次有界误差角域相交定位。
- 选择侧向观测点时核对可靠接收条件，不依赖虚构的误差概率分布。
- 按当前位置就近处理目标；选覆盖整个可能位置区域的清除点。
- 完成七点覆盖证书，或已清除 16 个后结束。发现目标未清除或证据冲突会明确记录未完成。

当前交付版本 `p3-region-routing-v2`。本地 76 个开发/压力场景和另外 100 个合成留出场景均全部清除，清除失败为零；留出集平均虚拟耗时约下降 34.7%。这些不是官方演练成绩，也不保证每个实际案例都提速。极近源聚集场景曾比旧策略慢，详见研究报告。

## 环境、输入和输出

Python 3.10+，numpy、scipy。本机已核验依赖。换电脑缺少依赖时，可执行 `python -m pip install -r requirements.txt`。

如果包不在旧策略旁边，可将已有配置复制到本目录的 `config.json`，或运行 `python run_robot.py --config "旧配置完整路径"`。也支持 `--team 队号 --port 2026`。程序不更改旧配置。

每场自动保存：

- `actions.jsonl`：完整请求响应、区域顶点、清除和结束证书。
- `summary.json`：清除数、测量数、路程、虚拟耗时、结束依据和未完成原因。
- `manifest.json`、`source_snapshot/`：依赖版本、源码哈希和当场源程序。

运行后优先返回这一场的 `summary.json`、`actions.jsonl` 和官方结束结果，官方 `.jlog` 单独保留供核验。程序无法从 API 得到隐藏的实际目标总数，因此 `actual_jammer_count` 留空，不把推断伪装成官方数据。

若连续三次请求不能确认执行状态，程序停止发送新动作；此时请从模拟器界面查看状态，勿并行启动另一程序。可读日志和本地覆盖判断不替代官方日志与成绩。

数学说明、全部离线结果和代码来源见研究目录 `B题建模第一版/contest/q3/models/m01-region-routing/`。旧策略、旧日志均保留。
