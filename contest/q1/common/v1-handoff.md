# 问题一第一版接口

这是研究分支上的已核验推荐接口，不是团队正式发布。上游 Q1-M01-v01/A01/R003；完整出处为 `../models/m01-bounded-bearing/`，源码和运行通过SHA-256绑定。

输入是同一未清除目标的有效方向观测，`position`为米，`bearing_deg`为度，误差界明确指定。主模型1°；接口舍入是否需要额外0.005°尚有语义歧义。

| 函数 | 输出 | 必须保留的条件 |
|---|---|---|
| `observations_halfplanes` | A,b | 正向角域；不可换成无方向直线 |
| `halfplane_region` | 状态、顶点、残差 | 不加任意截断；空集和无界必须向上传递 |
| `diameter` | 区域直径、最远点对 | 只接受非空有界区域 |
| `enclosing_circle` | 圆心、半径、支撑顶点 | 输入点的凸包必须包含真实源，才能作保证 |
| `summarize_region` | JSON可存储摘要 | 20米清除判定有数值余量；点/线段单独处理 |
| `outer_disk`和`clip_halfplanes` | 保守圆盘外包与裁剪 | 只在确有圆盘先验时使用，不改写问题一原定义 |

核心规则：D≤40不保证可清除；R≤20才给出存在安全清除点的充要条件（相对于当前区域）。任何计划采用的清除位置q还须满足所有顶点距离≤20。

若误差界、角度约定、半平面方向、圆形先验外包或数值容差改变，问题二及后续清除判据必须重新核验。若第一问改用更快包围圆算法，需再次与当前支撑点算法和独立凸优化对照。

本轮没有写入 `adopted.md` 或 `exports/`，没有把未经团队采用的内容发布到 `global/accepted-results/`。后续可以在实验中显式依赖本接口，正式写作前再确定采用状态。
