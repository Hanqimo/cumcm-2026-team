整理日期：2026-09-12。性质：模型符号参考与统一建议，不是论文正文中需要整表插入的“符号说明”，也不代表归档候选已被正式采用。

## 0. 使用范围与阅读方法

全局表严格保留已确认的16个基础符号，与当前 `templates/论文模版.tex` 的符号表一致。后续各节按模型补充局部对象。表中“原符号”用于查找既有文件，“建议符号”用于后续写作；仅基础16项已经在本次对话中确认，其余局部统一记法是本次整理的建议，尚未改写模型原文或程序。

主线范围为问题一交会定位、当前问题二均匀期望模型及最坏半径模型，以及用户指定的仓库根目录 `contest/q3` 中的 M01/M02。为防止遗漏全文可能引用的已有模型，第7—9节另外登记旧版第二问、正式题目工作区归档的第三问 M03—M05 和第四问 M01/M02。根目录 `contest/q4/state.md` 仍记为未开始，不能把归档中的第四问成果当作根目录已有采用方案。

**收录边界。** 收录物理量、信息状态、数学集合、约束、损失及目标，以及候选决策子模型自身的变量；不收录外包多边形的数值表示、圆弧离散边数、检测角分箱、积分节点、随机种子、采样编号、迭代计数、求解器状态和工程容差。规划模型的访问/扫描决策变量属于数学子模型，予以登记；用于求解这些变量的枚举、采样及求解器参数不登记。旧模型自身定义的连续松弛集合只在旧模型节注明，不把数值外包符号重新加入全局表。

**记号约定。** 全部位置是二维向量，坐标单位为米；角度推导使用弧度，数据表可标注度。单源省略源编号，多源用频道编号 \(j\) 标识源；\(i\) 表示该频道的检测序号，\(k\) 表示全任务阶段。纯积分哑变量、证明中任取的点及反例专用数值不另立符号条目。来源代号及可点击原文件见第12节；文件版本指纹见同目录 [notation-source-manifest.json](notation-source-manifest.json)。

## 2. 通用数学记法与信息约定（按需局部引入）

|---|---|---|

| \(\operatorname{wrap}(a)\) | \(((a+\pi)\bmod2\pi)-\pi\)，圆周角差归一化 | Q2-E；Q2-W |
| \(\varepsilon_j(s)\) | 源 \(j\) 在位置 \(s\) 的固定测角误差，绝对值不超过 \(\alpha\) | 用函数强调同地点误差不随重复检测改变；不附带独立或均匀假设 |

| \(\mathcal V(P)\) | 有界多边形 \(P\) 的顶点集合 | 顶点是精确多边形的数学对象；不指圆域离散化生成的节点 |

数学角域使用闭合的半平面交，允许包含顶点；正常无线电反馈的 \(d>5\) 等物理条件另加。不可在源与检测点重合时计算方位角。

## 3. 问题一：交会定位、直径与保证清除

来源：Q1，第1—6节；Q1-C。除表中明确指出的符号替换外，沿用原数学定义。

| 建议符号 | 定义/关系 | 原符号 | 单位/类型 |
|---|---|---|---|
| \(n_{\mathrm{obs}}\) | 同一源的正常示向度观测条数 | \(n\) | 整数 |
| \(u_i^-,u_i^+\) | \(u(\theta_i-\alpha)\)、\(u(\theta_i+\alpha)\)，角域两条边界射线的方向 | 同名 | 单位向量 |
| \(A_{\mathrm{ang}},b_{\mathrm{ang}}\) | 将全部角域写为 \(P=\{g:A_{\mathrm{ang}}g\le b_{\mathrm{ang}}\}\) 的矩阵和右端项 | \(A,b\) | 无量纲矩阵、m向量 |
| \(m_{\mathrm{ang}}\) | 半平面约束数量，原模型中为 \(2n_{\mathrm{obs}}\) | \(m\) | 整数 |
| \(v_\ell\)、\(n_v\) | 精确有界多边形的顶点及顶点总数 | \(v_i\)、\(h\) 或 \(m\) | m向量、整数 |
| \(g_a,g_b\) | 区域的一组最远点对，距离为 \(\operatorname{diam}(P)\) | \(a,b\) | m，二维向量 |
| \(c_D\) | 最远点对中点 \((g_a+g_b)/2\)，即同直径候选覆盖圆的唯一可能圆心 | 原文 \((a+b)/2\) | m，二维向量 |
| \(\mathcal C_{\mathrm{clr}}(K)\) | \(\{q:d_{\max}(q;K)\le r_{\mathrm{opt}}\}=\bigcap_{g\in K}B(g,r_{\mathrm{opt}})\) | \(\mathcal C(P)\)；Q1-C 的 \(K_\rho\) | 行动位置集合 |
| \(p\) | 当前机器狗位置，求最近保证清除位置时作为已知量 | 同名 | m，二维向量 |
| \(q_{\mathrm{clr}}^*(p;K)\) | \(\arg\min_{q\in\mathcal C_{\mathrm{clr}}(K)}\lVert q-p\rVert\)，集合非空时的最近保证清除点 | \(q^*\) | m，二维向量 |

关键关系保留为 \(\operatorname{diam}(K)/2\le\rho(K)\)，有界平面集还满足 \(\rho(K)\le\operatorname{diam}(K)/\sqrt3\)。存在同直径覆盖圆，当且仅当 \(\rho(K)=\operatorname{diam}(K)/2\)；存在保证清除位置，当且仅当 \(\rho(K)\le r_{\mathrm{opt}}\)。当前位置可以保证清除，则必须检查 \(d_{\max}(p;K)\le r_{\mathrm{opt}}\)。

Q1-C 的原文件将工程安全距离记为 \(\rho=19.5\) 米。本文不把这个实现值列入模型符号；改写物理保证清除集合时使用已确认的 \(r_{\mathrm{opt}}=20\) 米。引用旧计算结果时仍须说明旧实现保留了安全余量，不能声称旧结果按20米边界重新计算过。

## 6. 问题三主线：多源状态、清除与任务时间

真实相容源同时满足每次正观测 \(\lVert g_j-s^+\rVert\le R_j\) 与每次负观测 \(R_j<\lVert g_j-s^-\rVert\)。因此有 \(2(s^--s^+)^Tg_j<\lVert s^-\rVert^2-\lVert s^+\rVert^2\)。这里 \(s^+,s^-\) 是实际正、负观测点；不是两个可以独立选择的接收半径。

完成依据为：已清除数达到16；或者所有已发现源均清除，且其余每个频道均有不存在源的证明。计划中的未来扫描不能写入 \(\mathcal S^-\)、\(\mathcal E\) 或 \(\mathcal J^{\mathrm{abs}}\)。以上圆盘排除只适用于全向源。

## 9. 归档第四问：定向源与发现覆盖

来源：Q4-A、Q4-B。问题四继承前述位置、时间与光学定义，但增加源类型和发射朝向；不能沿用全向无信号删圆盘的逻辑。

| 建议符号 | 定义/约束 | 原符号 |
|---|---|---|
| \(\chi_j\) | 频道 \(j\) 的源类型，取全向或定向 | \(\tau\)，避免与动作时间 \(\tau_{\cdot}\) 混用 |
| \(\psi_j\) | 定向源的发射朝向角；全向源不需要此参数 | 原文 \(\varphi\) 或 \(\phi\)，rad |
| \(n_j\) | \((\cos\psi_j,\sin\psi_j)\)，定向朝向单位向量 | \(n\) |
| \(\mathcal B_{\mathrm{em}}(g_j,n_j)\) | \(\{s:n_j^T(s-g_j)\ge0\}\)，含边界的发射半平面 | 原文发射角度条件 |
| \(\mathcal R_{\mathrm{sig},j}\) | 全向为 \(B(g_j,R_j)\)；定向为 \(B(g_j,R_j)\cap\mathcal B_{\mathrm{em}}(g_j,n_j)\) | 有效接收位置区域 |
| \(\omega_j=(g_j,R_j,n_j,\chi_j)\) | 位置、半径、朝向与类型的联合未知状态；全向时朝向不参与条件 | 原文 \((g,R,n,\tau)\) |
| \(\mathcal X_{j,k}^{\mathrm{dir}}\) | 与实际历史相容的上述联合状态集合 | Q4-A 使用 \(\Omega\)；必须改名以免与目标圆域冲突 |
| \(K_{j,k}^{\mathrm{dir}}\) | 联合状态集合在位置坐标上的投影；计算最远距离时再明确闭包 | 原文位置相容对象 |
| \(\mathcal A^{\mathrm{cov}}\) | 需要证明可排除的任意凸子区域 | Q4-B 的 \(Q\)，与检测点搜索域 \(\mathcal Q\) 区分 |
| \(\mathcal S^-_{j,\mathcal A}\) | 同一频道实际无信号点的子集，且每个点到整个 \(\mathcal A^{\mathrm{cov}}\) 的距离均不超过1000米 | \(S_Q\) |
| \(\lambda_i\) | 凸组合权重，\(\lambda_i\ge0,\sum_i\lambda_i=1\)，用于 \(g=\sum_i\lambda_is_i\) | 同名；不是规划均值权重 |
| \(\mathcal T,\ell_\triangle\) | 构造发现保障的三角形集合与部署三角网的边长；作为扫描站布局设计，而非圆弧数值离散 | Q4-A 三角网、\(L\) |
| \(\mathcal S_{\mathrm{scan}}\) | 计划部署/访问的扫描站集合；实际负观测必须另记 \(\mathcal S^-\) | 三角网站、双圈站 |
| \(r_{\mathrm{in}},r_{\mathrm{out}}\) | 双圈扫描站部署的内、外圈半径 | Q4-B 几何构造中的两圈半径；m |
| \(n_{\mathrm{in}},n_{\mathrm{out}}\) | 两圈的扫描站数量 | Q4-B 的两圈点数；整数 |
| \(\mathcal C_{\mathrm{opt,cov}}\) | 用于后备光学搜索的尝试位置集合，要求 \(K\subseteq\bigcup_{q\in\mathcal C_{\mathrm{opt,cov}}}B(q,r_{\mathrm{opt}})\) | Q4-A 光学后备覆盖的数学目标；不登记方格步长 |

定向负观测表达为“\(\lVert s-g_j\rVert>R_j\)，或者该源为定向且 \(n_j^T(s-g_j)<0\)”。真实方位 \(\varphi_s(g_j)\) 从检测点指向源，发射朝向 \(\psi_j\) 则由源指向发射方向，不能用同一个角度符号。

若 \(\mathcal A^{\mathrm{cov}}\subseteq\operatorname{conv}(\mathcal S^-_{j,\mathcal A})\)，并满足表中的全子区域距离条件，则该区域内不存在频道 \(j\) 的源。这是连续几何覆盖条件；保存用于计算的网格编号、递归细分层数、位集及方向采样数不属于模型符号。

Q4-A 还定义了局部时间代理目标，归入候选决策子模型而非物理接收模型。与第8节一致，只登记其目标及参数的数学含义，不收录有限假设样本、朝向采样节点和估计过程。

| 建议符号 | 定义/用途 | 原符号 |
|---|---|---|
| \(\gamma_{\mathrm{rec}}(q)\) | 下一点接收机会在代理目标中的权重，取值在0—1之间；原算法用有限相容假设比例赋值，不是真实接收概率 | \(\hat p\) |
| \(\rho_{\mathrm{pred}}(q)\) | 接收后区域包围半径在代理目标中的预测值，不是连续最坏半径 | \(\hat r'\)；m |
| \(s_{\mathrm{last}}^+\) | 当前源末次实际有信号的检测位置 | \(s^+\)；m位置 |
| \(c_{\mathrm{plan}},\rho_{\mathrm{plan}}\) | 当前用于行动评分的位置代表点及区域尺度，原策略取其当前表示的包围圆心和半径 | \(c,r\)；m；不声称基于精确相容区域计算 |
| \(\tau_{\mathrm{loss,plan}}\) | 代理目标中的失联处理惩罚时间；属于该决策规则的设定，不是题定耗时 | 原评分中的附加惩罚；s |
| \(J_{4,\mathrm{plan}}(q)\) | 当前移动与检测费用，加按 \(\gamma_{\mathrm{rec}}\) 混合的“接收后接近与定位”及“失联后返回与处理”时间代理 | Q4-A 的 \(J(q)\)；s |

原评分的符号化对应为 \(J_{4,\mathrm{plan}}(q)=\lVert p-q\rVert/v+(\tau_{\mathrm{det}}+\tau_{\mathrm{sw}})+\gamma_{\mathrm{rec}}(q)[\lVert q-c_{\mathrm{plan}}\rVert/v+2\rho_{\mathrm{pred}}(q)/v]+[1-\gamma_{\mathrm{rec}}(q)][\lVert q-s_{\mathrm{last}}^+\rVert/v+2\rho_{\mathrm{plan}}/v+\tau_{\mathrm{loss,plan}}]\)。这只是原局部决策规则的单位统一，不是经验证的真实条件期望；不能把 \(\gamma_{\mathrm{rec}}\) 套用为 Q2-E 中由概率模型推导的预测概率。各实现给上述参数赋值的方法及实际数值留在算法说明中。
