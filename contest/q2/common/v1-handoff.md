# 问题二第一版接口

推荐方案 Q2-M01-v01/A01/R002，独立验证 V02。上游使用 Q1-M01-v01 的研究分支核验版本，当前没有官方模拟器测试结果。

输入：首次位置s、有效读数θ、误差界ε、1000至1500米接收半径范围、1800米目标圆域，以及上层指定的移动预算B和横向分离h。调用者不能传入隐藏的真实目标距离。

输出：第二点q、候选区域原始约束余量、最坏后验包围圆半径保守上界U、分箱宽度、保守最坏后验多边形、预计本步移动与检测耗时。有限空间搜索没有全局最优保证。

| 接口 | 用途 | 边界 |
|---|---|---|
| `planner.plan_next_observation` | 任意首次位置和方向的可执行选点入口 | 双侧有限网格；与R002精细实验网格不同；无可行网格点时返回诊断 |
| `first_region` | 首次观测的凸外包 | 省略5米内孔，采用外接多边形近似圆盘 |
| `candidate_margins` / `in_candidate` | 检查第二点安全与非退化条件 | 接收保证仅适用于全向源；θ、ε必须与首次记录一致 |
| `posterior` | 实际第二读数后的更新 | 只能用于有效direction；near/no_signal须另行处理 |
| `worst_radius_upper` | 连续读数分箱外包上界 | 不能把粗网格选点称为连续最优 |
| `to_global` / `to_local` | 将方向相关位移转成世界坐标 | 环境圆域不随首次位置平移，边界情形要重算P1 |

本轮给出四个移动预算的示例推荐，不选一个预算作为全题固定参数。第三问应结合其他目标、剩余搜索区域和后续清除路程选择预算。第四问可沿用定位区域和清除判断，必须替换全向接收保证。

通用入口已通过V03的原点、圆域边缘、非轴向读数及预算过小情形检查。边界情形会重新构建固定圆域的先验并评价方向两侧，不能只平移旋转原点数值表。其数值与R002精细表不必一致，必须记录实际网格和返回值。

导出给程序时使用原始JSON/CSV的完整精度；论文只显示适当小数。四个点都在移动预算边界，手工四舍五入后应重新检查约束或略向内收缩，不能把展示坐标当成精确可行点。

本版无信号不是正常预测分支：若全向前提、误差界、初始有效信号及候选约束均成立，它理论上不应出现。实际出现时应保留记录诊断前提或数值问题，不能默默沿用本版的保证。
