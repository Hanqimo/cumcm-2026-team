# 赛前资料库

本目录保存可以跨小问或跨届比赛复用的资料，不保存本届比赛的临时研究结果。

## 目录

- `problems/` 保存历年赛题、附件、分类索引和下载工具。
- `papers/` 保存优秀论文、官方讲评、来源索引和下载工具。
- `knowledge/` 保存建模方法、算法、领域知识和赛后复盘。
- `datasets/` 保存训练用公开数据和样例数据。

## 使用原则

- 同一份原始资料只保存一份，其他位置通过路径引用。
- 新增资料时记录年份、题型、主题、来源和本地路径。
- 原始 PDF、表格和压缩包不在原文件上修改。
- 能由脚本下载或生成的内容应保留脚本、来源和校验值。
- 大型二进制文件首次提交前评估是否需要 Git LFS。
- 本届比赛题面、数据和研究成果放在 `../contest/`，不要混入本目录。
