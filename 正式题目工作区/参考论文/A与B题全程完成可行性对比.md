# A与B题：由助手全程完成、用户验收的可行性对比

日期：2026-09-10。依据为本地两题题面、附件、现有论文分析，以及B题简单策略的一次完整演练。本报告评估后续工作的可达到水平，没有完成A题求解，也没有运行新的B题官方演练或正式测试。

## 1. 判断与前提

**若严格要求用户从头到尾只验收、不操作其他软件，当前优先A；若B题模拟器的登录、启动、正式测试及日志操作已能可靠自动完成，我更倾向B，因为它更适合通过程序与反馈持续改进，算法创新也更容易量化验证。**

这个条件不能省略。目前B的HTTP动作链和一次全向源演练已打通，但之前由用户操作模拟器启动与导出。本轮核对附件，只看到`enter/measure/clear/exit`四个机器狗接口，它们不等于模拟器登录、开启测试和导出日志的全部界面控制。现有证据不足以承诺“零手工完成B题”。这不等于证明无法自动化，而是尚未完成验证的交付依赖。

这里把“下限”定义为不依赖显著创新、完成必要检查后可以争取的保守交付水平，把“上限”定义为主要方法顺利落地并经充分验证后的合理目标。两者都不是成功保证或奖项预测。仅靠题目和文献，也无法给出可信的成功率百分比、名次或奖项概率。

## 2. 证据基础：两题不是处于同一进度

| 项目 | A题 | B题 |
|---|---|---|
| 任务核心 | 非线性热质传递及收缩下的内部状态和干燥时间 | 信息不完整时的搜索、定位、清除和成本控制 |
| 现有资料 | 12篇文献线索及逐篇分析，4篇本地全文，部分额外网页正文 | 24篇PDF全文及逐篇分析 |
| 已完成实际求解 | 尚无四问结果、未生成正式结果工作簿 | 简单策略在一次第三问演练中清除14/14个源 |
| 已知表现 | 只有模型路线与输入核查，不能声称数值已可靠 | 虚拟时间6446.675秒、路程27.25公里、移动耗时84.5% |
| 尚未验证的关键点 | 边界解释、收缩守恒、数值收敛及各处达标时刻 | 多场景稳定性、第四问全清、全套模拟器操作自动化 |

不能因为B已经跑了一次，就认定其所有问题解决；也不能因为A的PDE形式熟悉，就认为A已具有经过验证的保底答案。文献数量也不是选择依据：A的主要障碍是题给变量与模型闭合，B的主要障碍是组合策略及检验。

## 3. 完成水平的上下限

### A题

**保守可争取的完成水平**：采用明确假设的一维径向模型，按题给局部温度、含水率更新物性，处理给定半径变化，完成四问的数值求解、四个结果工作簿、所需表格与图，以及可复现代码。应至少检查时空收敛、非负性、边界通量、适当的守恒关系和终止时刻稳定性。

其优势是依赖顺序清楚：基础径向求解器稳定后，后续物性、长期计算和移动域可以逐层加入。结果文件由同一套计算数据自动生成，表格和论文之间容易保持一致。无法突破复杂模型时，仍可回退到有明确假设的较简单模型，而不是整体失去交付物。

但这个保守版本仍可能存在实质偏差：烘房湿度与固体干基含水率如何对应、长期边界如何延拓、潜热怎样处理、给定密度与收缩是否兼容。**程序能算完和方程离散收敛，只证明实现层面的一部分正确性，不能证明物理解释唯一正确。**

**合理上限**：建立守恒自洽、层次明确的模型，采用独立离散或简化解析极限交叉核验；对径向近似与有限圆柱端面效应、收缩表示、环境延拓和潜热选择做有针对性的对照。输出主结果，同时清楚指出哪些结论稳健、哪些时长依赖假设，形成一篇证据链完整的机理建模论文。

上限的边界在于题目没有药材内部实测温湿场供直接核验，相关文献也不是同一药材的标定数据。不能把网格更密、结果四位小数或采用复杂软件，表述成物理预测误差已经达到相应精度。

**较差情形**：模型选择反复，最后得到曲线平滑、表格齐全，但湿度边界或收缩质量账不一致；这一类错误不一定触发程序异常，会同时影响多个小问，是A最值得防范的失败方式。

### B题

**保守可争取的完成水平**：第一问完成可靠的区域几何计算，第二问给出可执行的候选观测区域和评价指标；第三问从已跑通的简单策略出发，保留有覆盖依据的搜索骨架；第四问构造与发射方向无关的保守发现机制，再完成定位、清除及退出判据。保守策略可能慢，但其可靠性可以按模块论证和测试。

当前真正得到官方演练支持的只是第三问一个案例的100%清除。第四问全清和跨案例稳定性仍是后续目标，不能写成已经达到的下限。

**合理上限**：把有界位置/朝向状态、按频道覆盖、主动观测、清除位置和任务次序统一组织成闭环策略。在保留安全回退的前提下，减少不划算的行走与检测；通过独立场景、困难边界场景和官方演练证明改进，再完成两问各三次正式测试及日志。理论部分说明何时可以确保发现和清除，实验部分说明实际快了多少、在哪些场景会变差。

B的上限主要体现为可量化的策略表现，而非单纯更复杂的算法。没有证据支持预先承诺缩短一半时间、达到全局最优或获得某类奖项。模拟器表现也不能单独代替论文的模型、论证和可复现性。

**较差情形**：在普通演练中很快，遇到最后一个朝外定向源或坏交会几何时漏检、循环、提前退出；或者程序本身有效，但正式测试/日志流程未完成。这些风险可能使某次交付不完整，必须保留保守回退并提前验证外部流程。

## 4. 可靠性必须拆开看

| 维度 | 当前更有利的一题 | 原因与限制 |
|---|---|---|
| 完全由文件和程序自动形成交付物 | A | 不依赖外部随机案例、登录和测试界面；模型正确性仍需审查 |
| 发现错误和获得明确反馈 | B | 清除返回、行动日志和虚拟计时能直接反馈操作效果；找全仍需覆盖证据 |
| 检查数值实现 | A可做得很强 | 收敛、守恒、退化模型和独立求解可检查实现；不能替代真实材料验证 |
| 检查目标是否实际清除 | B | 官方演练结束可核对真实数量及清除结果；正式测试不向选手显示全部真值 |
| 避免未经验证的物理假设 | B | 世界规则相对明确；A的相间湿度、潜热和收缩解释会影响答案 |
| 进度和交付形式的可预测性 | A | 可以逐问推进，计算与输出流程更容易固定 |
| 策略效果通过迭代改善 | B | 可用观测结果定位瓶颈，再比较模块改进；须防止只适应少数演练 |
| 当前已经存在可运行基线 | B | 有一次真实全向演练；A尚无数值基线 |

两题“错误很难被自己发现”的方式不同。A可能是在同一错误物理解释下两个求解器都收敛，B可能是在不够多样的测试场景中不断表现良好。应分别用模型假设对照和保留独立困难场景来减轻风险。

## 5. 本轮对B第四问保底难度的新核查

此前指出“定向覆盖尚未解决”是对现有实现的描述，不应误读为不存在保守构造。利用题目允许走到目标圆域外、接收半径至少1000米、有效发射角为闭合180°的条件，可以先把“保证发现”单独处理。

例如，在`[-2000,2000]×[-2000,2000]`布置间距500米的方形网格，共81个点，并在每点检测所有20个频道。对任一圆域内、非网格顶点的目标，它位于某个500米方格内，到四角的距离至多约707.11米。目标是这些角点的凸组合，因此任意经过目标的闭合发射半平面至少包含一个角点，且该点在最小接收半径内。若目标恰好落在网格顶点，使用其上下左右相邻网格点即可覆盖任意朝向；这些点距目标500米且都存在于所取网格。

因此，这是一个**按题设可论证的定向源发现覆盖构造**，不需要假设方向随机或等待信号恢复。该结论是本轮从题设推导，不是直接从参考论文搬来的结论。

按原点出发、先走到网格角点，再蛇形遍历81点，每点按1—20频道检测且暂不穿插清除：

- 行走距离为40000＋2000√2≈42828.43米。
- 检测1620次，换频道1619次。
- 仅发现扫描的虚拟时间约18284.69秒，即5.079小时。

这不是优化方案，也不是完整清除策略的总时间。它说明存在一个有限且可计算的发现成本基准；还需解决可靠抵近清除、正式接口运行开销及日志大小等问题。其虚拟时间低于100小时上限，不代表已证明完整程序满足所有限制。

本轮另对圆域内25445个间距20米的样本位置做了方向覆盖几何检查，未发现失败样本。检查通过不能替代连续区域证明，上述凸组合论证才是发现保证的依据；该检查也不是官方模拟器演练。

这一核查提高了我对B“能构造保守后备方案”的判断。创新的重点可以放在：如何大量减少这类保守扫描，以及如何将搜索与定位清除穿插起来，同时保留最终补扫机制。

## 6. 创新空间及能否被验证

### A：空间相对集中，适合把模型做扎实

值得做的方向包括：

1. 干基含水率、干物质质量与收缩速度统一的守恒建模。
2. 比较固定域映射和移动网格、研究半径插值与导数稳定性。
3. 在相同物性下开/关收缩，区分几何与物性改变对干燥时间的贡献。
4. 把数值误差与边界/模型假设的不确定性分开，指出最湿位置达标时刻的稳健程度。
5. 用一维与二维对照说明端面效应是否足以影响最终结论。

这些工作能提高论文质量，但守恒、网格收敛和正确单位首先属于必要质量要求；不能把采用ALE、有限体积或敏感性分析本身宣称为新理论。题目已指定经验公式，也不适合无依据替换扩散率或扩展到药效、能耗最优控制。

### B：组合决策空间更大，也更容易形成量化证据

值得做的方向包括：

1. 用有界可行域承担保证，用信息量或代价预测安排高效动作；两者职责分明。
2. 从“去估计中心”改成“去最近的安全清除位置”。
3. 同一停点服务多个频道，联合安排观测和清除次序，减少远距离往返。
4. 维护每个频道尚未排除的区域，复用历史停点，按需要启动补扫。
5. 将位置、类型、半径、朝向的可能性纳入第四问状态，利用有信号与无信号共同更新。
6. 设计明确的保守回退条件，让激进策略失败时仍有后备路径。

有界测角误差与扇形交集已有研究基础，不能把这一基本结构本身当成原创；[Tokekar与Isler的原论文](https://tokekar.com/pubs/tokekar2013asensor.pdf)研究的静态布置也没有直接解决本题全部动作成本和可见性约束。较有价值的贡献在于对本题约束的正确组合、具体新决策规则，以及能够归因的比较结果。

总体上，**B有更大的策略创新和实验优化空间，A有更集中的物理解释与数值严谨性空间**。两题都不必靠引入深度学习获得质量提升。实际新颖性还需对照相关工作判断，不能提前保证国际文献中无人做过。

## 7. 用户只验收时，应交付什么证据

| 验收对象 | A | B |
|---|---|---|
| 主结果 | 四问表格、result1—4.xlsx、干燥时长 | 四问方法、策略代码、演练记录、规定正式测试结果和日志 |
| 一键复现 | 从原始附件生成数值结果、图表及汇总 | 在接口就绪时自动运行、记录动作及生成结果分析；完整GUI链另验 |
| 正确性证据 | 方程量纲、边界定义、守恒/通量、时空收敛、独立对照 | 几何测试、按频道覆盖依据、清除/退出判据、串行幂等、计时核账 |
| 稳健性证据 | 边界延拓、潜热/几何假设、半径拟合敏感性 | 全向/定向、边缘朝外、最小接收半径、坏几何、10与16源等场景 |
| 效果提升证据 | 主模型相对简化模型的必要性和结论稳定性 | 相同自建场景集的模块对照，加官方演练验证；不能挑最好一局 |
| 必须解释的局限 | 真实物理结果依赖假设，无同材料内部观测直接标定 | 有限测试不能代替普适证明；效率改进不等于全局最优 |

工作计划也应不同：A先封闭最影响结果的模型解释，再完善求解器；B先验证完整操作链和保守后备策略，再优化效率。两题都应先产生可验收的基线，再提高复杂度。

## 8. 最终选择建议

**严格按当前“用户只验收”的条件立即选题：A优先。**我对其文件读取、计算、图表、结果工作簿和论文组装的自动化链更有把握；它的主要风险集中在我可以主动组织审查的模型假设与数值论证。

**若B的模拟器完整操作链已验证可由我完成：B优先。**现有代码与日志基础、规则明确的反馈环境、可构造的保守发现方案，以及较大的路径成本改善空间，更适合由我持续编码、测试、分析和修正。此时B的潜在完成质量和可验证性更有吸引力。

不建议目前同时深做两题。比较阶段可并行理解，但正式投入时应围绕一个主选形成完整闭环；另一个保留模型与资料作为备选。此处只是选题建议，没有替用户启动任何正式测试或实施完整求解。
