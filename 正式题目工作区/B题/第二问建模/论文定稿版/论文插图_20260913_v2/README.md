# 第二版论文插图：一般首次位置与反馈图拆分

本版按用户2026-09-13的审阅意见修改。旧版图件与代码保留在 `../论文插图_20260913/`，本次修改前的论文归档路径见 `inputs/revision.json`。

## 本版内容

第一张改为固定非圆心首次点 s1=(1200,0) 米，对比30度和90度两个首次示向度。原点算例中，改变示向度会旋转后验分布，但不改变其形状和归一化常数；非圆心处的圆域边界会截断不同方向的角域，故示向度也改变保留范围和归一化后的密度。两幅热力图使用统一色标，颜色是每平方米的位置密度。显示坐标为距离与相对示向角，不是距离和角度的联合密度；积分仍须使用极坐标面积元。

归一化使用径向权重积分的解析原函数与128点角度高斯积分，同时调用冻结的原几何积分核独立核对。30度与90度的归一化常数分别为7552.930303875267、26408.065032371742平方米，两个实现的差异均小于10⁻⁹平方米。第一张图只重新计算了首次后验，没有将原点算例的选点优化结果套用到新位置。

原第二张图拆为两个独立浮动图。`q2_feedback_regions` 是两种反馈的剩余区域（130×60毫米），放在完成概率定义之后；`q2_feedback_distribution` 是预测密度（150×43毫米），放在加权选点决策之后。它们继续使用原点、示向正东及 w=0.5 的已有结果，源数据逐字节保持不变。区域半径仍为16.8723、30.4273米，完成概率仍为37.34%。

`q2_posterior_general` 为160×78毫米。以上三件均提供 PDF、SVG、600 dpi RGB PNG；旧第三张候选点图保持不变并继续由论文引用，因此目前问题二共四张图。图内不放总标题，s1 使用普通圆点，正文明确写出每张图说明的现象和结论，图注只保留简短图名。

## 复现与技能

使用前版相同的 Python/Matplotlib 环境与 SimHei 中文字体，环境和技能来源见 `../论文插图_20260913/verification/environment.json` 及该版 README。本版继续遵循 scientific-visualization v1.2；相应技能文档与审查脚本快照复用前版 `skill/`。

运行 `src/plot_figures.py` 重画本版三件图，再运行 `src/verify_general.py` 核查两种首次后验及冻结反馈数据。`src/update_paper.py` 是带修改前哈希保护的一次性写入记录，不应重复用于日常重画。
