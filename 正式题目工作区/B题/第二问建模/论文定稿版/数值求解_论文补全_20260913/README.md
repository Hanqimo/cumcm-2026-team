# 问题二数值求解与论文结果补全

本轮在已采用的加权模型基础上补充通用数值流程、五组典型首次观测和原点算例的11个权重结果。没有修改模型的损失规则、先验、反馈区域或完成条件；旧实验结果保持原样。

## 结果来源

| 情形 | 权重 | 来源 |
| --- | --- | --- |
| a=0, beta=0 | 11个既有权重 | 冻结的期望损失与免补测概率实验 |
| a=1200, beta=30度 | 0.5 | 本轮独立网格与多初值搜索 |
| a=1200, beta=90度 | 0.5 | 本轮独立网格与多初值搜索 |
| a=1200, beta=150度 | 0.5 | 原点选点的平移旋转，并重新评价核对 |
| a=1700, beta=0 | 0.5 | 冻结的既有实验 |

[典型情形表](results/typical_cases.csv)和[原点权重表](results/origin_weights.csv)是论文表格的数据来源。文件保留未舍入坐标与指标，论文坐标保留一位小数、损失两位小数、完成概率百分数两位小数。典型情形显示坐标的舍入影响已经复算，小于相应指标的显示精度。

典型情形统一 w=0.5 仅用于比较，不表示存在题目给定或普遍正确的权重。角度输入为度，进入C++核后转换为弧度；内部坐标以首次点为原点、首次示向为横轴，CSV中的 q_x_m、q_y_m 是目标圆心坐标系下的实际位置。原点表用正y代表点保存，论文用正负号列出两个镜像点。

a=1200、beta=150度时，5至1500米、±1度的整个首次扇形都落在目标圆域内。初始区域及概率权重与原点情形仅差刚体变换，因此选点与两项指标可以变换后复用；本轮核对了最外位置距圆心的上界以及变换后高精度评价。这项等价仅用于满足上述条件的情形，不推广到被圆域边界截断的方向。

## 算法与预算

算法沿用冻结的C++几何/概率核和 Python 网格、多初值单纯形搜索。新增两例都从初始区域圆心及网格种子启动，没有用预知最优点初始化。

- 在初始区域边界外扩1501米的矩形内布置100米网格，再加入源区域尺度的较密网格及沿示向方向65个位置的邻近采样。所有点仍逐项检查原约束；外包矩形只是搜索包络。
- 选取5个空间分离的较优网格种子及初始圆心，进行无导数 Nelder–Mead 搜索，再从两个较优点高精度细化。目标始终是 (1-w)J/20+w(1-P_finish)。
- 粗局部搜索最多150步，精细局部搜索最多130步；精细停止参数 xatol=0.015米、fatol=2e-9，最后复算到level6、128份阈值扫描。
- 搜索过程中不同求积等级的阶数、分段细分深度及容差以 inputs/base_solver.cpp 的 settings 函数为准。最终位置/径向/角度基础阶数为28/36/14；外层使用两倍角度阶数比较误差，并继续细分。
- 每例外部运行超时300秒。本轮实际新增搜索分别评价2959、5977个配置，耗时约10.5、22.1秒（两例并发，本机运行时间，非独立硬件性能基准）。

原11权重数据保留原运行状态。其 w=1 的求解曾加入1e-10 J/20作为选取代表点的微小数值项；论文仍采用纯完成概率目标，并按既定规则在并列解中偏好较小J。这里报告的是数值优选解，没有连续全局最优证明。

## 核查

详见 [核查结果](verification/numerical_checks.json)。

新增两例提高求积精度后，J的变化分别约为-2.8e-9和1.32e-6米，完成概率变化接近浮点舍入量。15个代表反馈使用独立极坐标射线求交与独立支撑圆计算核对，包围圆半径上下界最大差约0.000421米；另对每例进行20000次联合先验抽样，J与完成概率均在4个标准误的核查范围内。模拟复用主程序的包围圆核，因此只独立核对概率积分；几何另由射线和支撑圆核查。0.1、1、5米多方向邻域检查未发现更小目标值。

这些验证不把建模先验变成物理事实，也不证明搜索覆盖了所有连续位置。对于新的首次观测，须重新执行算法，不能将五行典型表当成完整查找表。

## 复现与文件维护

`inputs/manifest_start.json` 保存原代码哈希、修改前论文快照和本轮范围。源代码中仅调整了搜索入口的权重集合与原专用于多权重的快捷分支；几何和概率核未修改。`inputs/search_trial_original.py` 保存修改前搜索入口。

使用仓库此前相同的Python+NumPy与C++17环境，先编译 `src/trial_solver.cpp` 为 `solver`、`inputs/base_solver.cpp` 为 `base_solver`。从两个 `inputs/a1200_b*_baseline.json` 读取区域信息和圆心种子，分别运行 `python src/search_trial.py --a 1200 --beta 30` 和 `--beta 90`。已有结果目录会阻止同名运行，应在新目录复制代码与输入后复现。再运行 `python src/verify_and_export.py` 复算并导出表格。

`src/write_paper_results.py` 是一次性论文写入记录，含修改前哈希检查，不要在已修改的论文上重复运行。新增文字及两表另存为 `results/新增求解与结果正文.tex`。主文维护于 templates/论文模版.tex，并同步论文初稿与独立问题二正文。旧候选点图移至数值结果段落旁，其图件未重画。
