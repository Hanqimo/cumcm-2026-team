# 问题二论文插图（2026-09-13）

本目录保存首次检测点为原点、首次示向正东（a=0、beta=0）的三张插图，以及绘图数据、代码和核查结果。三张图只对应这个算例，不代表所有首次位置与示向度。主论文与独立问题二正文使用同一组图片；图的总标题与说明放在 LaTeX caption 中。

## 三张图

| 文件名 | 内容与读图要点 | 正文位置 |
| --- | --- | --- |
| `figures/q2_posterior.pdf` | 左图展示均匀位置先验所在圆域和首次可行区域；右图用距离与相对示向角展开狭窄角域，颜色仍是单位面积位置密度。1000米以内的面积密度相同，1000至1500米逐渐降低。 | 首次观测后的概率更新 |
| `figures/q2_feedback.pdf` | 固定 w=0.5 的既有选点，展示第二次读数的预测密度及满足20米包围圆条件的反馈。下方用270度和300度两个真实反馈区域解释完成条件。 | 综合评价与选点决策 |
| `figures/q2_candidates.pdf` | 左图保留11个权重对应的两支对称候选点，右图比较相同候选点的期望损失与完成概率。虚线只表示权重顺序，不将点间或镜像分支间的位置认定为候选区域。 | 候选区域 |

每张同时提供PDF、SVG及600 dpi的RGB PNG。宽度均为160毫米，高度依次为70、110、80毫米，按正文的实际宽度绘制。PDF字体已嵌入；SVG将字形保存为路径，便于跨设备保持外观。仅热力图底层栅格化，其余线条、文字、圆与点保持矢量。`verification/` 中保存PDF实际渲染、灰度预览和元数据检查。

## 数据来源与处理

原始结果来自 `../../期望损失与免补测概率_20260913/`。原有实验目录未修改，`inputs/manifest.json` 保存来源路径、输入哈希和修改前论文的归档位置。`inputs/candidates.csv` 是原点算例的全部11个权重结果，未选择性删除候选点。`inputs/trial_solver.cpp`、`base_solver.cpp` 和两份验证脚本为只读来源副本；`src/figure_kernel.cpp` 在其基础上增加固定点的绘图输出入口，未修改原几何或概率算法。旧入口被改名后未调用，编译器对这些旧入口发出的缺少返回语句警告不影响实际执行的绘图入口。

本次没有重新进行候选点优化。第一张图由现有模型的解析后验公式生成；第二张图在既有 w=0.5 选点 q=(813.824371479152,521.018510869701) 米处补算读数剖面及两个剩余区域；第三张图直接使用冻结的候选表，并按模型的反射对称性绘制对应的负 y 坐标。

热力图颜色为 p1(g)，单位是每平方米，**不是以距离和角度为积分变量的联合密度**。若从这幅展开图计算位置概率，必须带上极坐标面积因子 r。没有把位置先验改成距离均匀。该算例的归一化常数为 27633.943490930556 平方米，最大后验密度约为 3.61874×10⁻⁵ 每平方米。

第二张图的横轴使用度，因此将程序按弧度输出的密度乘以 pi/180，得到每度的密度。角度样本包含几何分界与20米半径阈值的根，最大间隔0.02度，未对曲线额外平滑。阴影按 rho<=20 筛选，与当前点能否直接光学定位的条件不同。本例强信号、无信号和原地光学定位概率均为0，完成概率为0.373364048581301；满足完成条件后需要移动到最小包围圆圆心。

270度与300度仅用来解释阈值两侧的情形，并非随机抽取的统计样本。它们的剩余区域均为四边形，绘制的四个顶点是计算出的实际交点，无需以多边形逼近圆弧。两张局部图的横、纵坐标使用真实米制坐标且保持等比例，各自显示80米的跨度。

权重图用顺序蓝色表示 w，颜色范围0至1；端点和中间代表权重另有文字标注。包围圆用蓝色实线，20米参考圆用橙色虚线，完成反馈用绿色斜线阴影。三者对白底的对比分别约为5.19、3.87、4.59；灰度时部分颜色亮度接近，故用线型、阴影和直接标注补充区分。此检查不等同于所有打印条件或色觉差异下的无障碍认证。

## 数值核查

`verification/numerical_checks.json`、`independent_figure_checks.json` 保存可复核结果。

- 后验归一化常数的解析计算与原积分核相差约4.4×10⁻¹⁰平方米。
- 对绘图剖面按“度”积分，总概率约0.999999998866，完成概率与高精度积分结果相差约3.9×10⁻⁸。
- 绘图剖面计算的期望损失与高精度积分值相差约2.6×10⁻⁶米。
- 两个示例各用独立极坐标射线构造32002个边界样本，并用独立支撑圆枚举核查。包围圆半径分别为16.8722833365米、30.4272805524米，完成条件得到确认。
- 原候选点的全局最优性没有证明；图中报告的是已有数值搜索的优选结果。

在本目录运行。实际环境版本记录在 `verification/environment.json`。绘图使用本机 Microsoft Word 提供的 SimHei 中文字体；外部电脑请使用具有相应授权的中文字体，并修改脚本中的字体路径。

```bash

/Users/hanqimo/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 src/plot_figures.py
/Users/hanqimo/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 src/verify_figures.py
```

程序不会覆盖原始实验目录，但会重新生成本插图目录中的派生数据与图件。先完成论文编译，再运行 `src/inspect_exports.py` 更新PDF检查与渲染。`src/insert_figures.py` 是本次插图写入的操作记录，含修改前文件哈希保护，不应作为日常复现步骤重复执行。图注另存于 `data/figure_captions.tex`，修改前的论文已保存到 `templates/修订记录/20260913_122054_问题二三张插图/`。
