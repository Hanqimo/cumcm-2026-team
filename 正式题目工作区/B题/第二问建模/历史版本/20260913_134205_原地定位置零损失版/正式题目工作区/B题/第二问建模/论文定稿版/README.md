## 当前模型

原有定位损失规则保持不变。强信号损失为零；无信号损失为剩余区域的最小包围圆半径；正常示向度先检查整个区域能否在当前点20米内完成光学定位，能则为零，否则取区域半径。按预测概率平均后得到 J(q)，单位为米，它不是估计位置与真实位置之间的误差。

新增 P_finish(q) = Pr(rho_Z(q) <= 20 | I1,q)，表示第二次检测后无需再次无线电测向，即已能确定保证清除位置的概率。允许移动到剩余区域的最小包围圆圆心；它不等于原地光学定位概率。强信号、无信号和正常读数均计入完成事件，无信号也可能使剩余区域足够小。

定位效果综合评价函数为 F_w(q) = (1-w) J(q)/20 + w [1-P_finish(q)]，决策明确写成 min_{q in Q} F_w(q)。w 属于 [0,1]，是完成概率指标的权重；w=0 恢复原期望损失决策，w=1 最大化完成概率。20米来自光学定位尺度，是量纲处理的评价约定；权重不是题目物理参数，也没有经过验证的唯一正确值。

候选区域 Q_cand 是不同权重下最优解集合的并集。并列解均保留；展示单个代表点时，完成概率相同时可按 J 择优。数值结果是有限权重下的优选点，不是连续全局最优认证。候选集合可能为曲线或分离部分，不预设有面积，不填充两支镜像序列之间的空白。原来的 J 容差区域与按最短移动距离选择方案已撤下。

按用户确认，接收概率函数由 w(d) 改为 p_rec(d)，w 仅作新模型权重。保留共享固定接收半径、同地点误差固定的贝叶斯解释，以及均匀先验和不同地点误差先验独立性属于额外假设的说明。

## 已有计算证据

[加权实验及核查](../期望损失与免补测概率_20260913/结果汇报.md)与[候选点 CSV](../期望损失与免补测概率_20260913/results/全部权重候选点.csv)保留原始运行状态。实验报告中的“尚未采用”描述运行时状态；本 README 记录之后的论文采用决定。

原点、正东情景中，w=0 时 J=25.0757米、P_finish=26.62%；w=0.5 时 J=25.6746米、P_finish=37.34%。期望损失增加约0.60米，完成概率提高约10.72个百分点。该情景的11个权重对应22个镜像代表候选点；原地光学定位概率均为零。其余三个边界情景中，两项指标可能已共同达到较好值，改变权重不一定产生不同的代表点。

已完成的概率积分收敛、独立射线几何、联合先验模拟和邻域复核见实验 `verification/`。这些检查的适用范围沿用原记录；非零最优值情景没有连续全局最优证明，四个情景不能代表全部 (a,beta)。原实验结果保留不变；新增两个一般位置情形的优化及五行情景表、十一行权重表见下方“数值求解与结果”。尚未开展先验敏感性研究。
