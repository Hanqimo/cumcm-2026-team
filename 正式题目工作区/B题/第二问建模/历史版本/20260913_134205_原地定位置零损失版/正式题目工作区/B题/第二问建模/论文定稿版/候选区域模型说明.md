# 期望定位损失与完成概率加权候选区域

日期：2026-09-13。状态：用户已确认采用；论文模版、论文初稿和独立问题二同步。已有四个代表情景的加权实验作为依据，本次未重复运行优化。

## 输入、指标与决策

输入为首次正常示向度信息 I1=(s1,beta)，其中 s1=(a,0)；源位置可行区域为 K1，检测点搜索范围为 Q。输出是给定权重的优选位置、不同权重的候选位置集合及各位置的 J 和 P_finish。源位置空间与检测点空间必须区分，结果使用时需旋转回实际坐标。

保留原模型 J(q) = E[L_Z(q) | I1,q]。L 只有在整个剩余区域处于当前检测点20米范围内时取零，其他情况取最小包围圆半径。强信号必为零；无信号一定不能原地定位，因此 L_N=rho_N。

新增 P_finish(q) = Pr(rho_Z(q) <= 20 | I1,q)。这一事件表示无需继续无线电测向，而不要求当前点就能光学定位。若成立，可以移动到剩余区域最小包围圆圆心，再光学定位与清除。按三种反馈展开为 P_H + P_N 1{rho_N <=20} + integral f_Theta 1{rho_theta <=20} dtheta。无信号分支不能漏掉；零概率的不可实现反馈不计入。

评价函数 F_w(q)=(1-w)J(q)/20+w[1-P_finish(q)]，在 q 属于 Q 时最小化。w 是完成概率项的权重，取 [0,1]；w=0 最小化 J，w=1 最大化完成概率。20米是光学定位尺度，用来消除量纲，不保证归一化后的 J 小于1。改变归一化尺度会改变同一 w 的实际偏好，因而 w=0.5 不是客观的“等重要”或经验证的最优偏好。

接收概率函数使用 p_rec(d)，权重使用 w，按用户明确选择消除原 w(d) 的重名。概率分布描述固定未知量的认识；两次共享固定 R，不同地点的固定误差采用独立先验，同一地点不能重新抽样。

## 候选区域的含义

Q_cand = union_{w in [0,1]} argmin_{q in Q} F_w(q)。固定权重给出一次选点决策，扫描权重保留不同偏好下的最优位置。并列解均属于对应的最优解集合。端点 w=1 可能有多个同为100%完成概率的位置，展示代表点时再按 J 择优，但不能把代表点说成完整最优解集合。

单参数加权一般产生曲线、若干分支或点集，不保证形成有面积的二维区域，不允许把镜像分支之间填色后宣称全部合格。对称性只在几何和先验都对称的情景中使用，例如首次点位于目标圆心时关于首次示向方向的反射；一般 (a,beta) 下，目标圆的裁剪可能破坏这种对称。

内点权重 0<w<1 下，精确最优解不会被另一个点在两个指标上同时弱优且至少一项严格优；端点只优化一个指标，存在并列解时可再按另一指标选择代表点。加权和不保证覆盖非凸多目标问题的所有非支撑有效解。论文将此集解释为所采用加权偏好下的候选集合，不声称遍历一切可能偏好。

原来的 Q_epsilon、默认1米容差、0.5/2米敏感性设置以及在容差区域内取最近点方案已经退出当前模型。原文件另存历史版本，不将两种候选机制叠加。

## 计算与核查口径

每个位置的 J 和 P_finish 由同一首次后验、共享半径条件和同一反馈几何计算，可在不同 w 间缓存复用。正常反馈的完成判据在 rho_theta=20 处切换，积分需在阈值附近细分。外层搜索采用覆盖网格与多个初值的局部细化，最终优选点提高积分精度复算；不能只沿上一个权重的解单向追踪而忽略其他分支。

既有实验权重为 0、0.05、0.1、0.2、0.35、0.5、0.65、0.8、0.9、0.95、1。后续可在位置变化明显的区间加密权重，但尚未加密的中间位置不能当作已验证最优点。图中连线只表示变化顺序，实际推荐点必须有对应的指标复算值。未获得连续全局界时报告“本次搜索得到的数值优选点”。

原点、正东算例中，w=0 的 J=25.075721932282米，P_finish=0.266211850594134；w=0.5 的 J=25.6746025616283米，P_finish=0.373364048581302，增加0.5988806293463米，换取10.7152197987168个百分点的完成概率增量。这两点的原地光学定位概率均为零，核实了新增指标与原损失零值事件的差别。

另一个分支核查点取 a=1700、beta=0，q=(770,0)，其无信号概率约0.01624073，rho_N约15.075443米，而当前点到剩余区域的最远距离约1030米。因此该反馈计入完成概率，L_N仍为约15.075443米；这不是优选点，只用于检验无信号事件的处理。

四个代表情景的完整输出、积分加密、60组独立几何检查、360000个联合先验模拟场景及邻域复核，见 `../期望损失与免补测概率_20260913/结果汇报.md` 和 `verification/`。其中非零目标值情景没有连续全局最优证明；模拟共享几何内核，仅独立核对概率部分，几何由另一路射线表示核对。不把该批计算推广为整个连续参数域的普遍结果。
