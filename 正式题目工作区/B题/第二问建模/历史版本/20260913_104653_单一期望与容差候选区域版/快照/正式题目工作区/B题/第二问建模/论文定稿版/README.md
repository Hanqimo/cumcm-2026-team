当前论文仅采用**基于贝叶斯更新的期望定位损失模型**。用首次观测更新对固定未知源位置、接收半径的判断，再预测第二次反馈，并选择平均定位损失最小的检测位置。最坏情形模型及相关比较已从当前正文撤下，完整历史状态见[双模型归档](../历史版本/20260913_024419_期望与最坏双模型版/README.md)。

## 当前模型

定位损失衡量检测后尚未消除的位置不确定性。三种反馈分别说明计算规则：强信号为零；无信号为更新后区域的最小包围圆半径；正常示向度先判断整个剩余区域能否在当前点20米内完成光学定位，能则为零，否则取该区域半径。该量以米计，不是估计位置与真实位置之间的误差。

期望目标统一记为 J(q)，明确求解 min J(q)。保留首次观测的贝叶斯更新、两次检测共享固定接收半径，以及同地点误差固定的解释。均匀先验与不同地点误差的先验独立性是额外假设，平均效果以这些假设为前提，不能把它们当作题目已给条件。

检测点候选区域记为 Q_epsilon，由 J(q) <= J* + epsilon 定义。默认1米容差及0.5/2米对照尚未通过新计算验证；在近优区域内，进一步推荐距离首次点最近的复核位置。结果须区分连续模型的理想区域和有限网格得到的近似区域。

本目录不采用期望面积或最坏半径作为第二套论文方案。期望半径已有数值证据见 `../一般情景求解_20260912/结果汇报.md`，其情景范围、误差检查与最优性结论以原报告为准。本次只修改论文结构与表述，未运行新的优化，未生成新区域结果或图表。

## 编译

在本目录执行 `latexmk -xelatex -interaction=nonstopmode -halt-on-error -outdir=build 第二问模型.tex`，随后将 `build/第二问模型.pdf` 复制为本目录的 `第二问模型.pdf`。整篇论文在 `templates` 目录按已有 VS Code latexmk 配方编译。
