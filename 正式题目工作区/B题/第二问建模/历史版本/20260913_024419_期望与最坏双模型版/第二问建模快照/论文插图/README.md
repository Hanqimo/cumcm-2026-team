# B题第二问：论文插图

本目录提供三幅成组的论文插图，分别解释反馈区域与包围圆、展示两种目标的空间变化、说明最坏目标的分支平衡机制。使用已完成的均匀先验期望模型与无分布信息最坏模型，计算与绘图均由代码完成，未修改原求解器或既有模型结果。

## 可用于论文的图注

**图1　第二次检测后可行位置集及其最小包围圆。** 以第一检测点在原点、首次示向度正东为基准，在最坏目标方案 \(q_W=(969.35,497.73)\,\mathrm m\) 处展示两类控制反馈。（a）第一次可行区域、第二次示向度约束及反馈区域的整体位置；（b）无信号反馈下的近端可行区域；（c）控制最坏正常反馈的远端可行区域。橙色与青色区域分别表示两类反馈后的位置支持集，虚线圆表示其最小包围圆，圆心以十字标记，控制圆的两个边界点以圆点标记。两类包围圆半径均约49.04米，各坐标轴采用等比例尺度。

图1的补充解释：图中 \(d_2=1000\,\mathrm m\) 和 \(d_2=d_1\) 为无信号相容性约束的边界，不能把前者解读为接收半径已知且恒等于1000米。无信号区域满足 \(d_2>\max(1000,d_1)\)。图中绘制位置支持集的闭包，严格不等式边界的加入不改变本例包围半径的上确界。正常反馈所用示向度约为314.35384°，按从正东逆时针的角度约定。为便于辨认，第二次方向约束只画出局部射线。

**图2　期望半径与最坏半径的空间分布及1%近优区域。** 横、纵坐标为第二检测点位置，星形标记表示期望目标方案 \(q_E\)，菱形标记表示最坏目标方案 \(q_W\)。颜色表示目标值相对于各自方案最优值的百分比增幅，颜色越浅越优；棕色曲线表示目标增幅约为1%的边界。两图采用相同坐标范围和百分比色标，超过10%的增幅统一采用最高色阶。图中仅展示北侧局部区域，南侧对应方案可由关于横轴的反射得到。

图2的补充解释：左图颜色为 \(100[J_R(q)/J_R(q_E)-1]\)，右图颜色为 \(100[W(q)/W(q_W)-1]\)，因此相同颜色表示相对性能损失相同，不能据此认为两图中的绝对半径相同。相应基准值约为25.07572米和49.03634米。期望目标采用基础模型的位置、接收半径与测角误差均匀先验，并保留首次反馈后的条件更新；它不是对第一次扇形区域直接均匀平均。最坏目标仅使用相容支持集，不使用概率权重。图中的“最优”沿用数值方案名称；期望方案未证明连续全局最优，最坏方案已有不足0.001米的全域数值间隙，但该界使用双精度几何余量而非定向舍入区间算术。

**图3　沿两方案连线的最坏半径分支变化。** 令 \(q(t)=q_E+t(q_W-q_E)\)，其中 \(t=0\) 和 \(t=1\) 分别对应期望方案和最坏方案。青色实线为正常示向度反馈的最坏半径，橙色虚线为无信号反馈的包围圆半径，深色上包络为两类非终止反馈损失的最大值。沿该截面，从期望方案向最坏方案移动时，正常反馈最坏半径逐渐减小，而无信号分支半径增大；两者在最坏方案附近接近平衡，使总最坏半径由约50.38米降至约49.04米。

图3的补充解释：参数 \(t\) 用于构造候选检测点的空间截面，不是时间或实际航行轨迹。曲线包括 \([-0.25,1.3]\) 的少量外延，以展示交点两侧的变化趋势；一维截面本身不构成二维全局最优证明。原模型中强信号和原地光学定位成功均计为零损失，在这里的候选位置上不会控制上包络，因此图中不单独绘制零损失线。

## 数据、精度与核查

基准坐标和半径直接读取 [既有比较结果](../worstcase/runs/R001/comparison.json)，未将四舍五入后的坐标用于计算。原始源文件的 SHA256 固定在 [input_contract.json](input_contract.json)；复现前自动核查，源模型改变时停止，以免把不同版本的模型混入同一组图。

| 项目 | 计算方法与核查结果 |
|---|---|
| 热力图原始网格 | \(800\le q_x\le1040\)、\(400\le q_y\le700\)，间距2米，共18,271个点 |
| 期望半径 | 原积分器 level 3；1%轮廓另用 level 5 回代，两参考点与原 level 6 结果的差异均小于0.00003米 |
| 网格最坏半径 | 原连续角度分支定界器逐点计算，单点上下界间隙不超过0.002米 |
| 最坏目标色块插值 | 先分别对正常反馈与无信号分支作双线性插值，再取最大值，显示步长0.25米；该步长不是新增计算点间距 |
| 1%等值线 | 期望等值线由原网格线性插值；最坏等值线由本局部区域的两个控制分支圆弧构造，避免总最坏值插值跨越狭窄谷底产生伪折线 |
| 轮廓回代 | 共检查280个顶点或线段中点；相对“1%”的最大偏差，期望曲线约0.000439个百分点，最坏曲线约0.004067个百分点 |
| 反馈几何 | 独立按2401个极角求射线可行区间；两个控制点相距约98.07267米，所绘区域均被对应半径约49.03633米的圆覆盖 |
| 分支曲线 | 311个候选位置，步长 \(\Delta t=0.005\)，各点连续角度上下界间隙不超过0.00002米 |
| PDF检查 | 每份1页，中文可提取、字体嵌入；三份PDF均已渲染并逐图检查标注、公式、坐标比例和边界 |

轮廓核查是数值抽查，不是连续曲线的严格区间证明；圆弧表示依赖本局部区域的控制分支，不应直接推广到整个候选域。几何图和分支图均沿用原损失函数，而非另建绘图专用损失。详细机器可读证据见 [preparation.json](data/preparation.json)、[checks.json](data/checks.json) 和 [manifest.json](manifest.json)。

分支图绘制正常分支下界、无信号分支保守上界和总最坏值上界；总最坏值与两条分支的逐点最大值之间，最大数值差约为0.000020米，低于图上可见尺度。旧文件保护核查见 [preservation_check.json](data/preservation_check.json)：原有100个文件中99个内容完全未变，原入口 README 只在末尾追加插图链接，原模型、求解代码和数值结果均保持不变。

## 复现

依赖 Python 3、C++17 编译器 `clang++`，以及 [requirements.txt](requirements.txt) 中的 Python 库。当前字体配置使用 macOS 的宋体与 Times New Roman；在其他系统上运行时，需要在 `src/draw_figures.py` 的 `setup()` 中设置已安装的中文字体。

在本目录建立独立环境并运行以下命令，完整复现会更新本目录的生成数据和成图，不会写入上级模型目录。

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python src/reproduce.py
```

若只改字号、标注和配色，可直接运行 `.venv/bin/python src/draw_figures.py`。改变计算逻辑、等值线或输入模型后，应重新运行完整复现入口并检查PDF，不应沿用原验收结论。完整入口依次执行数据生成、三图导出、数值核查和文件清单生成。

| 文件 | 内容 |
|---|---|
| `src/figure_backend.cpp` | 调用已有求解器的批量计算接口 |
| `src/prepare_data.py` | 网格、分支曲线、独立几何数据生成 |
| `src/draw_figures.py` | 三幅图的版式、配色与矢量导出 |
| `src/check_data.py` | 等值线回代、包围圆覆盖、上包络和基准点核查 |
| `src/reproduce.py` | 完整复现入口与文件、字体、分辨率检查 |
| `data/heatmap.csv` | 所有原始网格点的期望值与最坏分支上下界 |
| `data/branch_curve.csv` | 沿两点连线的逐点计算结果 |
| `data/geometry.json` | 几何多边形、圆心与控制点 |
| `data/contours_1pct.json` | 实际画出的两条1%轮廓 |

`build/`、生成的 `src/worst_backend.hpp` 和本地虚拟环境已被忽略。数据生成只从原 C++ 源文件取出计算函数，省略原命令行入口；没有改写原模型的几何算法。全部文件仅保存在本地，未自动提交或推送。
