# 问题二论文定稿版

本版将第一版的期望半径损失与论文中的最坏半径准则统一，正文采用精简后的符号体系。两种方法均评价第二次检测并完成能够原地保证成功的光学定位后的剩余不确定性，区别仅在对未来反馈取期望还是取上确界。

## 文件

- `第二问模型.tex`：可独立编译的入口，补齐论文前文中的基本记号。
- `第二问正文.tex`：与 `templates/论文模版.tex` 的问题二章节逐字一致的正文快照。
- `第二问模型.pdf`：独立模型的编译结果。
- `核查记录.md`：模型口径、关键边界与编译检查。

整篇论文直接维护于 `templates/论文模版.tex`。后续若修改问题二，应同步更新本目录正文，独立入口通过 `\input` 引用正文，不重复维护模型公式。

## 本次定稿内容

统一使用一个分支损失 `L_z(q)`：若整个反馈可行区域到当前检测点的最远距离不超过20米，取零；否则取该区域的最小包围圆半径。无信号采用更新后的实际区域半径，删除附加惩罚参数；正常示向度也执行同一光学定位判据。期望与最坏模型共用区域、损失、搜索域与候选区域定义。

保留第一次观测的贝叶斯更新、共享接收半径、固定地点误差及新地点误差先验独立性的说明。期望模型使用额外的均匀先验与独立性假设；最坏模型只使用题目允许的状态范围。

本目录采用期望半径目标，不采用第一版另行研究的期望面积目标。已有数值证据仍见 `../一般情景求解_20260912/结果汇报.md` 与 `../worstcase/结果与对比.md`，其情景覆盖与验证范围以原报告为准。本次修改未重新优化检测点，不新增数值最优性结论。旧版模型及结果保留供追溯。

## 编译

在本目录执行 `latexmk -xelatex -interaction=nonstopmode -halt-on-error -outdir=build 第二问模型.tex`，随后将 `build/第二问模型.pdf` 复制为本目录的 `第二问模型.pdf`。整篇论文在 `templates` 目录按其既有 VS Code latexmk 配方编译。

定稿正文新增候选区域的性能约束、两种准则的分别输出、默认1米容差及0.5/2米敏感性对照，并在区域内按最短移动距离推荐检测点。该容差属于策略设置，尚未通过数值实验选择。边界需网格细化和损失复核；缺少全局误差界时只输出数值近似候选区域。详细计算规范与适用范围见 `候选区域模型说明.md`。
