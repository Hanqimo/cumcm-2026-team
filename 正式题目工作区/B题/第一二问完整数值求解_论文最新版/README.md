# 第一、二问完整数值求解代码（论文最新版）

本目录按 `templates/论文模版.tex` 当前采用的模型整理，可单独复制到其他目录运行。程序从观测参数重新计算，不依赖仓库其他文件夹，不需要历史算例作为初值，也不调用比赛接口。来源文件及其 SHA-256 见 `provenance.json`。

## 1. 安装和快速运行

需要 Python 3.10 或以上、NumPy、SciPy，以及支持 C++17 的 `clang++` 或 `g++`。第一问的线性规划使用 SciPy 的 HiGHS；第二问的几何与积分使用本目录提供的 C++ 源码，Python 负责搜索和结果管理。

在本目录打开终端后执行。

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python build.py

# 第一问：38 m 等边三角形反例
python run_q1.py examples/q1_triangle.json --out outputs/triangle.json

# 第一问：可清除区域及距当前位置最近的工程清除位置
python run_q1.py examples/q1_clearable.json --out outputs/clearable.json

# 第二问：原点、正东示向度，比较三个权重
python run_q2.py solve --a 0 --beta 0 --weights 0 0.5 1 --out outputs/origin

# 第二问：一般首次观测位置和方向
python run_q2.py solve --a 1200 --beta 30 --weights 0 0.5 1 --out outputs/general

# 验证两问的几何与概率计算
python verify.py --out outputs/checks

# 从头复算论文典型组合、完整权重表和第一问算例
python reproduce_paper.py --out outputs/paper
```

输出目录须为新目录；再次运行时换一个名称，避免覆盖已有结果。第一次使用第二问入口时也会自动编译，修改 C++ 文件后会自动重新编译。可通过环境变量 `CXX` 指定编译器。上述命令适用于 macOS/Linux；Windows 可使用 WSL，或在已配置 g++ 的环境中调用 Python，虚拟环境激活方式按系统调整。

## 3. 第一问的输入、算法与输出

输入格式例如如下。所有坐标、距离均为 m，示向度为角度制，正东为 0°，逆时针为正。

```json
{
  "epsilon_deg": 1,
  "observations": [
    {"position": [-500, 0], "bearing_deg": 0},
    {"position": [0, -500], "bearing_deg": 90}
  ],
  "current_position": [100, 100],
  "engineering_radius_m": 19.5
}
```

`current_position` 可省略；提供它时才计算最近清除位置。默认测角误差界为 1°，默认工程清除半径为 19.5 m。修改这些参数可做算法试验，复算本文时保留默认值。

程序将每次观测写成两个有向半平面，先进行可行性和四个坐标方向的线性规划。对于非空有界交集，枚举满足全部约束的直线交点，再求最远顶点对和最小包围圆。包围圆先检查最远点对的直径圆；若不能覆盖，再枚举三点外接圆。简单实现的半平面交复杂度为 O(m³)，包围圆最坏为 O(h⁴)，其中 m 为半平面数量，h 为顶点数。

输出中的 `status` 区分 `empty`、`unbounded`、`point`、`segment`、`polygon`。有界时同时给出顶点、直径及其端点、包围圆圆心/半径及支撑点、同直径圆能否覆盖区域，以及是否满足物理清除条件。

物理清除条件使用 `cover_radius_m <= 20`。工程行动位置则要求到所有顶点的距离不超过 19.5 m，并选择离当前位置最近的一个。工程条件比物理条件更严格，因此物理上可清除时，19.5 m 工程位置集合仍可能为空。程序会分别输出二者的判断。距物理阈值不足 10⁻⁷ m 时，`physical_threshold_near_boundary` 会提示浮点敏感性；程序没有把物理阈值改为 20−10⁻⁶。

这里的 P 按论文第一问定义，仅由测向角域构造。因此，单个角域可能无界；代码没有用人工裁剪框把它强制变成多边形。第二问另行将目标圆域和接收范围加入 K₁。

## 4. 第二问采用的模型

输入为首次位置 s₁=(a,0)、正常示向度 beta，以及一个或多个权重 w。`a` 以 m 为单位，`beta` 以度为单位。代码允许任意有限 a≥0 和角度；若首次正常观测在模型下的概率为零，会明确报错。

固定未知的源位置、接收半径与地点误差采用论文中的主观先验，源位置在半径 1800 m 圆域内按面积均匀，接收半径 R 在 [1000,1500] m 内均匀，不同地点的误差各在 ±1° 内均匀。首次观测后联合更新，两次检测始终共享同一个 R。重复检测同一位置不会产生新的独立误差，程序因此拒绝 q=s₁。

K₁ 同时保留首次角域、目标圆域以及 5 m 至 1500 m 的距离限制。对于每个候选点，代码分别构造强信号 H、无信号 N、正常示向度 theta 下的剩余区域。无信号分支要求第二次源距同时超过 1000 m 和首次源距，因此包含两次共享接收半径带来的信息。

当前采用的损失是所有分支下剩余区域的最小包围圆半径，强信号分支也保留其实际半径。积分得到期望损失 J，单位为 m；包围圆半径不超过 20 m 的概率记为 `P_finish`。综合目标为 `F = (1-w) * J/20 + w * (1-P_finish)`，固定 w 后最小化 F。

`P_finish` 表示第二次检测后不再需要无线电补测，移至包围圆圆心即可光学定位。`P_onsite` 仅为额外诊断，表示在当前检测点即可定位的概率，不参与 F，不用于把损失清零。若首次区域已经满足半径不超过 20 m，`solve` 直接返回 `no_second_detection_needed` 和清除圆心，不再搜索第二个检测点。

## 5. 第二问数值流程与精度

内部坐标以首次点为原点、首次示向方向为横轴。初始区域与各反馈区域使用直线和圆弧描述；有限支撑点包围圆结合圆弧最远点迭代，求连续区域的包围圆，并记录半径上下界之差 `mec_gap`。严格距离边界按极限边界参与几何计算，连续先验下不影响面积积分和半径上确界。

概率积分在首次角域的极坐标中进行，保留面积元中的径向因子 r。先对同一个接收半径解析积分，再以分段 Gauss–Legendre 积分处理源位置，正常示向度方向再做自适应积分。在几何变化点及半径穿越 20 m 的位置拆分区间，减少完成概率阶跃对积分的影响。

搜索范围为距 K₁ 不超过 1500 m 且不同于首次点的位置，允许位于目标圆域外。先用 100 m 网格覆盖外部范围，并在初始区域尺度附近加密；每个权重选取五个分散起点及初始包围圆圆心进行 Nelder–Mead 优化，再对两个较优起点细化。最终候选点评价统一使用 `level=6, scan=128`，并检查周围 0.1、1、5 m 的八个方向。邻域检查是诊断，不是连续全局最优证明。

精度等级 0 至 6 依次提高空间积分阶数和自适应深度。`scan` 控制在几何分段内搜索 20 m 阈值交点的采样数。`depth_capped` 非零表示部分自适应区间达到了深度上限，应结合不同等级的差值、概率质量残差及几何间隙判断；单独调高等级不等于获得严格误差保证。对极窄的首次可行区域或阈值附近结果，建议增加积分与阈值扫描精度并单独检查区域几何。

不同权重得到的是一组数值候选点。对 a=0 或 beta=0°/180° 的对称场景，`candidate_points.csv` 同时输出镜像候选点；`candidates.csv` 保留每个权重的一项代表解。固定权重下可能还有其他等价解或平坦最优区间，代码不宣称解唯一，也不把有限候选点连线所围区域全部视为最优区域。

## 6. 单点、几何查询与输出字段

```bash
# 查询首次后验支持区域和包围圆
python run_q2.py info --a 1200 --beta 30

# 在题目原坐标系下评价给定点，默认权重 0.5
python run_q2.py evaluate --a 0 --beta 0 --q 813.824371479152 521.018510869701

# 内部坐标输入：q 的横轴沿首次示向方向
python run_q2.py evaluate --a 1200 --beta 30 --q 458.353466053093 275.448404116768 --frame internal

# 给定第二次反馈，查看剩余区域圆弧与包围圆；theta 为角度制
python run_q2.py geometry --a 1200 --beta 30 --q 1459.2 467.7 --kind normal --theta 260
```

Python 接口的 `frame=global` 为默认值，输入 q 与 theta 都使用题目坐标系。`frame=internal` 时，q 相对于首次点和首次示向方向，theta 也相对于首次示向方向。底层 C++ 的 `geometry` 模式使用内部坐标及弧度，通常无需直接调用。几何查询中的 `center`、`points`、`arcs` 为内部坐标，`center_global` 则为题目坐标；空反馈区域的 `nonempty=false`，其半径占位值不能解释为合法的零损失反馈。

| 主要字段 | 含义 |
|---|---|
| `x_global, y_global` | 题目原坐标系下的候选点，m |
| `x, y` | 内部坐标下的候选点，m |
| `J` | 期望剩余包围圆半径，m |
| `P_finish` | 无需补测即可确定保证清除位置的概率，0 至 1 |
| `F` | 给定权重下的综合评价值，无量纲 |
| `P_H, P_N, P_normal` | 三种反馈的预测概率 |
| `P_finish_N, P_finish_normal` | 对完成概率的联合贡献，并非条件概率 |
| `probability_residual` | 三种反馈概率之和减 1 |
| `mec_gap` | 包围圆迭代的最大半径间隙，m |
| `distance_K1` | 检测点到首次区域的距离，m |
| `admissible` | 单点查询是否满足候选搜索范围 |
| `optimizer` | Nelder–Mead 的停止状态、迭代数及最终单纯形尺度 |

搜索输出还包括 `evaluations.csv`、`multistart.json`、`neighbors.json`、`initial_geometry.json` 和 `summary.json`，便于追踪每个数值结果。单点查询允许评价搜索范围外的位置，但通过 `admissible` 标出；搜索本身排除这些位置。

## 7. 已执行的验证与复现边界

`verification/checks/report.json` 保留本次实际运行的详细报告。验证包括第一问的 60 组随机观测和 200 组最近清除位置、第一问各退化状态与 20 m 边界、第二问 16 条论文参照记录的重算和积分精度对照、对称性、强信号非零半径、无信号也能完成的分支、非法输入，以及 20000 次条件联合先验抽样。另用独立极坐标区间采样和有限支撑圆枚举核验第二问几何。

第一问 200 组检验中，SLSQP 的停止状态逐项保存；部分样本报告线搜索未正常终止，不能据此称其获得了优化器认证，但本次全部样本的枚举解可行，且与独立计算的目标距离差在 10⁻⁴ m 检验阈值内。相应数值统计和完整状态可在 `q1_projection/cases.json` 中核对。

联合先验抽样独立核验概率积分，但复用 C++ 包围圆模块，因此不单独充当几何验证。独立几何采样给出有限样本的一致性证据。网格和多起点优化给出数值较优解，不提供连续全局最优证书。

论文原有点的直接重算用于确认模型一致性；重新搜索时起点、权重列表及浮点计算可能造成末位坐标变化，应比较 J、完成概率和 F，而不要求坐标逐位相同。`reference_results` 不作为搜索输入。所有随机核验固定种子，验证报告记录 Python/依赖版本及源码散列。第一问提供的是论文合成观测与几何检验，第二问提供的是给定首次观测后的选点计算。
