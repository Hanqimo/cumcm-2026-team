# 2026 B 第三、四问：相似子问题与优秀论文的处理方法

整理日期：2026-09-11。范围限定为上一轮已有论文库；按“子问题需要完成什么”筛选。本篇区分**原论文实际做法、原文验证结果、本次迁移判断**。论文结果均为作者报告，本次未复现实验，也未运行今年的模拟器。

## 1. 筛选结果：四个核心子问题、两个辅助子问题

今年第三问需要在数量和位置未知的情况下，通过逐次测向、移动与清除，自动处理全部全向源，并减少总时间。第四问进一步加入类型及朝向未知的定向源，改变了观测的可获得性和无信号的含义。两问都涉及“依据当前信息选择下一动作”，也涉及“怎样确认任务已经完成”。

## 2. 最像第三问的闭环：2022 B 问题1（3）

### 2.1 B035：把一次定位变成可反复调用的状态更新，再向后试算几轮

原文：[基于计算几何与带阈值启发式搜索的无人机无源定位模型](<D:/math modeling/documents/papers/B/2022/2022-B035-official-display.pdf>)，重点读PDF第15—20页；第4页查看信息假设。

**情景为什么导向这种模型。**一次选择哪些无人机发射信号，会影响其他无人机的本轮定位，也会改变下一轮可用发射机的位置精度。因此，仅追求本轮误差下降最多，未必让后续最快收敛。

**原文的处理链。**

1. 第15—16页先把单轮接收者的行动拆成三步：识别信号来源；利用先前建立的几何定位模型估计位置；用“理想位置减估计位置”的位移向量完成调整。
2. 第17页才处理“本轮选择谁发射”。用各无人机偏离理想点的距离平方和作为状态评价量 (L=\sum_i d_i^2\)。每个发射机组合是一条决策树分支。
3. 这里“阈值”的含义是**最大向前搜索层数 (N)**。遍历至该深度，选评价值最小的后续方案，先执行通向该方案的第一步，再以新状态继续选择。贪心是 (N=1) 的特例。
4. 决策树示例说明：某一步先修正一个误差大的基准点，本轮未必最好，却能改善下一轮的定位条件。这个例子承担了“为什么要多看几步”的论证功能。

**怎样展示有效。**第18页比较随机、贪心、固定3机启发式及3/4机启发式的误差收敛；第19—20页给出具体选择序列、达到精度所需轮数和信号数量，而非仅画最终队形。

**用于今年时要修改。**可以借鉴“基础定位模块＋候选动作＋有限步试算”的组织，但论文第4页有地面端掌握无人机位置的假设；今年执行策略不能用隐藏的真实源位置来算价值。评价应基于已有测向约束、剩余候选区域、未清除频道、当前位置和累计代价。原文减少的是误差或决策轮数，今年应计算实际虚拟时间，不能把“多看几步”直接称为时间最优。

**值得学的写法。**先解释本轮动作如何影响未来，再给出决策树与评价量，然后拿贪心作对照。算法名称出现在结构说明之后。

### 2.2 B086：只用可接收的角度做局部调整，另设全局指标评价

原文：[基于局部最优模型的无人机位置调整策略与仿真定位](<D:/math modeling/documents/papers/B/2022/2022-B086-official-display.pdf>)，重点读PDF第12—19、24—25页。

**情景为什么导向这种模型。**论文从信息不共享出发：单架无人机无法执行依赖全部真实坐标的全局调整，因此直接把本机能接收到的角度作为局部目标的输入。

**原文的处理链。**

1. 先做初始位置预处理，缩小偏差范围。第12页解释其价值不仅是减小误差，还能减少后续邻域搜索与信号发射次数。
2. 对待调整无人机，列出测得角度向量 (z)，由理想编队的几何关系得到目标角度 (y)，最小化 (f=\|z-y\|^2\)。第13页给出一架无人机的具体角度示例，再推广到其余无人机。
3. 设计两套发射机轮换方案，比较每轮选圆周上3架与2架发射的效果；仿真中在当前点的小邻域作离散搜索，反复更新。
4. 第14页单独定义全局误差，并明确它只用于评价方案，未被无人机用于位置调整。执行流程以预定循环次数控制结束。

**怎样展示有效。**先用同一初始数据比较两方案的误差及信号代价；第19页在其计数口径下报告方案二的信号次数约为方案一的19%，同时明确这些次数只作方案间比较。随后第24—25页加入10组人为高斯扰动，观察误差随循环次数的变化。

**用于今年时要修改。**最应借鉴的是区分“策略输入”和“评价指标”：演练结束后才知道的真实源数、真实位置可以评价策略，不能作为搜索中的输入。原文的角度邻域试探也不是免费计算；今年换地点试探会发生真实移动、检测成本。固定循环次数只能作为预算或应急限制，不能证明已经清除全部干扰源。

**值得学的写法。**具体对象示范目标函数 → 利用对称性推广 → 列可执行轮换步骤 → 解释评价量的信息权限 → 同条件比较 → 多初值检验。原文数值收敛不等于对任意初值的全局最优证明。

### 2.3 B030：先建立可靠基准，再分阶段调整其他对象

原文：[无人机遂行编队飞行中的纯方位无源定位](<D:/math modeling/documents/papers/B/2022/2022-B030-official-display.pdf>)，PDF第17—23页。

论文利用题给数据，选取初始半径同为98 m的FY02、FY05、FY08所在圆为基准，先调整基准组的角度，再调整其他无人机的角度，最后调整径向位置。第22页汇总公式及迭代步骤，第23页给出调整后的坐标。

它提供的是另一条思路：**先改善后续计算所依赖的基准条件，再处理其余对象，并把耦合变量分阶段求解。**但基准选择使用了旧题给出的初始坐标，今年不能据未知源的真值分组。可借鉴分阶段论述，不宜原样借用其选基准规则。

## 3. 最像第三问完整搜索的部分：2023 B 问题3

### 3.1 B311：从边界开始递推，用覆盖边界来决定何时结束

原文：[基于主要目标法的测线设计问题](<D:/math modeling/documents/papers/B/2023/2023-B311-official-display.pdf>)，PDF第10—13页。

**情景为什么导向这种模型。**固定坡面上，沿等深线延伸的测线水深不变，覆盖宽度更易控制。先限制为此类平行测线后，二维布线可化为相邻测线位置的一维递推。

**原文的处理链。**

1. 第一条测线的外侧覆盖边缘与测区西边界相接，解释为既避免漏测，也减少边界外的覆盖浪费。
2. 利用水深与位置关系、条带几何和重叠率关系，把下一条测线位置表示为当前测线位置确定后的可解量。
3. 取允许重叠率下界10%，依次生成测线。
4. 检查最后一条的实际覆盖外边界。第13页算得第34条已经覆盖东边界，因此删去多算的第35条；报告34条、总长68海里。

**这里最有价值的推导顺序是：首步可行 → 相邻步保持覆盖 → 最后一条覆盖边界 → 停止。**这比“设置若干测点，运行到次数上限”更能说明任务完成。

**用于今年时要修改。**第三问可以借鉴覆盖递推与停止证据，但必须把连续测线覆盖改成“实际检测点对指定频道提供的覆盖”。走过一段路不等于这段路上测过所有频道。半径未知时，保证性论证应使用已知下界1000 m，不能使用1500 m或样本平均半径；还要单独确认已发现源均已清除。

原文是在特定测线结构下进行构造，不能因设置最小重叠率便宣称已经排除全部曲线、不同方向等方案，证明全局最优。

### 3.2 B226：构造方案后，再用结果表、图形和另一种搜索检查

原文：[多波束测线布设](<D:/math modeling/documents/papers/B/2023/2023-B226-official-display.pdf>)，PDF第17—21页。

论文先把总测线长度写成目标，将完整覆盖及10%—20%重叠写成约束，再用贪心思想递推布线；给出34条测线的具体位置和布线图，总长125936 m，即68海里。随后用模拟退火所得结果作对照，并分析坡角变化的影响。

它的写作优点是**结果可以追溯到可执行坐标**，并用“浅处覆盖窄所以测线密，深处覆盖宽所以测线疏”解释图形。另一种搜索所得结果接近属于数值支持，不是全局最优证明，特别是对照方法的目标口径还需要核对。

用于今年，策略比较应在相同场景上报告清除完整率、总时间、移动距离、测向次数和失败清除次数；同时给出轨迹和动作日志，解释时间到底节省在哪里。

## 4. 最像第四问模型扩展的部分：2022 B 问题2

### 4.1 B035：先展示旧算法失效，再增加例外分支

同一篇B035的PDF第20—22页，从圆形编队转到锥形编队后，讨论发射机编号判别、共线与共圆定位问题。第21页用图展示四点共圆时两定位圆趋于重合，交点精度变差。

其补救包括：预先约定发射顺序以识别来源；遇到共圆情形，本轮不调整；对始终落在不利共线配置中的FY13安排专门轮次、更换发射机组合。随后报告不同初始误差下的收敛曲线与重复运行观察。

**值得学的是“原模型的适用条件 → 新情景破坏哪一条件 → 针对失效机制修改动作 → 验证修正”的论证。**重复成功只能支持测试范围内的表现，不能取代所有情形的证明。

今年第四问需要首先修改观测逻辑：第三问全向源下，某频道无信号可以排除该观测点周围保证可接收的区域；第四问中也可能是位于定向源背面，因此不能继续整圆排除。这才是模型扩展的主要理由，而非简单在第三问算法中添加一个“源类型”标签。

### 4.2 B086：把复杂目标分解成几种可以解释的基本操作

同一篇B086的PDF第19—24页，先给三个几何引理，分别对应调整出正三角形、把点调整到边上指定分比位置、把点调整到正三角形中心；再按“外框 → 边界点 → 内部点”组合成完整编队调整流程。论文先检验基本操作，再展示整体坐标与共面程度的变化。

这提供了适合今年第四问的推导和写作组织：把完整策略拆成可单独陈述输入、输出与有效条件的模块，例如“发现某频道”“缩小位置候选集”“到达可清除范围”“处理无信号和未发现频道”。每个模块说明依靠什么观测、何时成功、失败转向何处，再组成总流程。

上述模块名称是本次迁移建议，不是B086中的原始算法。原文的理论几何可行性也不自动等于其离散微调程序有限步精确达到目标，研读时应分开理解。

## 5. 最像第四问覆盖变化的部分：2023 B 问题4

### 5.1 B226：用拟合效果决定是否继续细分区域

同一篇B226的PDF第22—25页，首先解释全区使用平均水深的问题：浅水位置会漏测，深水位置会过度重叠。于是依据等深线走向先分4区，分别拟合平面，复用第三问的覆盖几何和布线方法；当部分区域拟合误差过大时，再分成6区。

这里的实质是：**找到第三问局部成立的区域，把新问题拆成若干可复用的旧问题；拟合失败触发继续分区。**论文使用粒子群求平面拟合参数，但真正支撑分区的理由是地形及拟合误差，不能把粒子群当成迁移重点。若自行实现这类线性平面拟合，通常可直接用线性最小二乘，不必为了复刻论文另加智能优化。

第25页按区域报告测线数、长度、漏测和超重叠。论文解释某区沿用相邻区测线延长线导致漏测，最终报告总漏测3.48%。这个例子同时说明：**各子区方案拼在一起，需要重新检查不规则区域和接缝。**

今年不能根据未观察到的源朝向预先作这种全知分区；可以根据已有观测状态分阶段处理，但仍需检验整个搜索域及全部未清除频道。旧论文允许漏测的折中不能直接用来满足今年的“全部清除”。

### 5.2 B477：记录初版失败，解释为什么必须改方案

原文：[多波束测深合理探测方案的设计及效果分析](<D:/math modeling/documents/papers/B/2023/2023-B477-official-display.pdf>)，PDF第14—20页。

处理链为：用学习模型辅助从坐标查询地形数据 → 依据局部梯度与覆盖关系逐段生成路线 → 发现起始线不同会造成路线差异、局部漏测和不稳定 → 按等高线分区，修改步长与区域参数 → 对部分平缓区域另行拟合，并比较不同起始线 → 合并路线与计算指标。

原文第16—17页虽然使用“自适应飞蛾火焰”名称，其与题意直接相关的部分是：用局部梯度控制方向，用相邻条带重叠控制间距，并用局部近似进行位置更新。第18页的失败路线和改进理由，比单独一张通用算法流程图更有参考价值。

第20页报告漏测率0.04%，同时指出区域交汇处还需二次处理。这个值是该论文自己的报告，不应未经统一计算就与其他论文的漏测数值作严格排名。学习模型拟合度高也不能单独证明梯度准确或全域无漏测。

用于今年，可学习它的论证方式：展示第三问策略在某种定向源配置下的具体失败轨迹，说明失效是可见性、几何条件还是停止规则造成，再用同一情景展示修正效果。不要仅写“考虑到第四问更复杂，对算法进行改进”。

### 5.3 B311：明确主次目标，但检查实际结果是否支持目标

同一篇B311的PDF第13—17页，依据地形、等高线和梯度划分3区，优先考虑覆盖，再依据相邻等高线间距选择下一条测线，最后累计曲线长度。它示范了如何说明多目标中的主次关系。

但其最终仍报告2.3%漏测。因此“优先覆盖”属于建模意图，不能改写为“已经证明完全覆盖”。今年论文应分别写清：要求是什么、模型约束是什么、测试实际达成什么。

## 6. 辅助参照：2024 B 问题3、4如何组织连续决策和不确定性

原文：[生产过程中的决策优化设计](<D:/math modeling/documents/papers/B/2024/2024-B159-official-display.pdf>)。

**问题3，PDF第14—18页：**把零件、半成品及成品的情况组织成状态；把检测、拆解等列为动作；分项列出成本和收益；随后写“当前收益减当前成本，加后续期望收益”的递推，用递归和记忆化求解。结果既有决策表，也翻译成生产流程中的实际操作。

这一组织方式适合今年：先定义状态和动作实际改变了什么，再解释为什么要考虑后续代价。直接照搬完整动态规划未必可行；今年含连续空间、多频道和信息不确定性，状态规模大得多。论文给定递归深度等终止办法，也不能据此保证今年任务完成。

今年可按附件实际计时统一代价：

\[
T=\frac{L}{5}+5N_{\mathrm{measure}}+N_{\mathrm{switch}}+3N_{\mathrm{attempt}}+2N_{\mathrm{success}}.
\]

其中attempt包含成功及失败清除尝试；clear指定目标频道不会改变测向机当前频道。该公式来自今年附件，不是B159原式。它的用途是把少走路、少测向、少切频道与少失败尝试放在同一时间尺度上。

**问题4，PDF第18—21页：**从“给定次品率”改为“样本反映次品率的不确定性”，假设伯努利抽样和均匀先验，得到Beta后验；对问题2各策略的利润函数按后验积分，重新比较16个策略。论文报告多数情形的最优决策不变，情况6有变化，并继续考察先验参数影响。

值得学习的是：**旧模型哪些参数变得不确定 → 不确定性如何进入原决策函数 → 新旧策略是否变化 → 变化幅度是否值得增加复杂度。**今年可以保留位置、半径、类型和朝向的多个可能解释，但不能无依据假设均匀先验或同点重复测量的独立高斯误差。先维护与题设有界误差相容的候选集合，是一种与上述思路相通、但需独立建立的方案。

## 7. 提炼成今年第三、四问的建模与行文要领

| 要解决的论证问题 | 优秀论文提供的样例 | 我们写第三、四问时应交代的内容 |
|---|---|---|
| 为什么这样建模 | B086从局部可用角度引出局部目标；B226从平均水深导致漏测引出分区 | 先写信息或几何障碍，再写变量、约束和算法 |
| 基础公式怎样组成完整策略 | B035把定位模块嵌入决策树；B086用引理组合整体调整 | 单次测向、候选集更新、下一动作选择、清除、剩余搜索之间的接口 |
| 下一动作为什么合理 | B035比较一步贪心与有限步试算 | 动作改变了什么信息、后续成本怎样估计、估计用了哪些可见数据 |
| 为什么可以结束 | B311逐条覆盖并核对最后边界 | 已发现源是否全部清除；未发现频道是否仍有可能藏源；结束所依赖的证据 |
| 第四问为何必须修改第三问 | B035展示共圆失效；B477展示初版路线漏测 | 明确指出无信号解释、覆盖区域和停止规则中失效的部分，再给修正 |
| 怎样让结果可以复核 | B226列测线坐标和分区指标；B035列动作序列 | 轨迹、频道、观测、动作原因、成本、清除结果及测试记录 |
| 怎样证明改进有效 | B035多策略同条件比较；B086多初值；B477失败前后比较 | 相同演练场景下比较基线与改进版；报告完整率和时间分项，并保留失败案例 |

建议第三问正文按以下顺序组织：**可用信息与时间成本 → 单源观测更新 → 未知多源的搜索与调度 → 完整性与终止条件 → 具体算法 → 演练及正式测试结果。**

第四问紧接着写：**第三问哪些条件不再成立 → 定向可见性及无信号的新解释 → 候选信息与动作规则的修改 → 覆盖/终止依据的修改 → 对照实验和正式测试结果。**两问可以复用算法框架，但必须说明新增分支的数学理由。

特别需要补足、且这些旧论文不能直接替我们解决的，是未知数量条件下的完整性与定向源的发现保证。第四问没有信号可能因为源在射程外、在辐射背面、已清除或频道无源；不能将它简单当作“附近无源”。同样，连续几次没搜到新源或已经清除了10个，都不构成已经找齐的证明。
