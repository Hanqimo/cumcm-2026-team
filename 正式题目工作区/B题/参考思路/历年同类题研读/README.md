## 建议阅读顺序

第一轮：**P01 → P02 → P04 → P05 → P11**，依次读建模动机、信息边界、覆盖终止、结果解释和验证结构。手册已经将这些经验映射到今年四问。

第二轮：P03 检查几何分支，P06 检查定义与区域接缝，P07 检查状态和费用，P10 检查跨问复用，P12 检查模型修正依据。P08、P09 作为备查，不能因为算法多就优先采用。

## 阅读与核验范围

本地官方展示校准库有45篇A/B/C论文，本次按任务选择12篇；其中10篇进行相关章节定向研读，P08、P09为摘要与相关文本初筛。用现有证据索引和论文画像定位候选页，再核对实际PDF。公式、图表及关键评价共核对 **35个原始页面（论文30页、官方讲评5页）**，不是对这些论文进行完整质量评级。

12篇现有PDF均重新计算SHA-256，并与其OCR记录的来源哈希一致。页数、阅读范围、已看原页与哈希见 [论文清单与核验](<D:/math modeling/正式题目工作区/参考论文/B题/历年同类题研读/论文清单与核验.json>)。

补充旧题来自官网原始压缩包；2020 B阅读DOCX正文，2015 A与2011 B提取DOC中的可读题意文字，用于结构判断，未依赖复杂公式或版式。新增的是题目文件，不是声称已有的优秀论文。未复现历史论文实验，未实施新的模拟器演练或正式测试。

手册中三测点反例做了独立交点枚举与数值核验；定向方格覆盖给出了证明和参数算术检查，二者都不是模拟器成绩。见 [几何核验记录](<D:/math modeling/正式题目工作区/参考论文/B题/历年同类题研读/assets/几何核验.json>) 和 [核验源码](<D:/math modeling/正式题目工作区/参考论文/B题/历年同类题研读/assets/几何核验.py>)。
