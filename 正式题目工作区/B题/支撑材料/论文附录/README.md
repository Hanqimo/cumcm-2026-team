# 论文附录合并说明

`三四问附录.pdf` 包含文件清单和完整源码，可接入最终论文附录；它只是附录素材，不是完整论文。源码按相同文件哈希去重展示，每组列出所有实际路径，独立运行的策略目录仍各自完整。

进入本目录后执行 `xelatex appendix.tex` 或 `tectonic appendix.tex` 可独立编译。需要 ctex、Fandol、fvextra、xurl、hyperref。源码读取路径为本目录的上一级支撑材料根目录。为避免编译中间文件混入提交包，建议指定单独输出目录。

合并总稿时引入两个TeX片段，并使源文件路径相对于总稿的实际目录可解析；也可将本PDF完整接到最终论文附录。第一、二问的源码和材料清单需另行合入。不要只在正文放外部链接替代完整源码附录。
