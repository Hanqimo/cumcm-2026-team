## 环境和运行

已在 Python 3.10.11 下验证。安装依赖：

```shell
python -m pip install -r requirements.txt
```

在本包根目录执行以下自检；队号只是占位符，`--check` 不联网：

```shell
python q3/v6/run_robot.py --policy v6 --team CHECK_ONLY --check
python q4/M32/run_robot.py --policy joint --team CHECK_ONLY --check
```

实际运行需题目提供的官方模拟器。将相应策略目录中的 `config.example.json` 复制为 `config.json`，填入本队队号和HTTP端口（默认2026）。在模拟器选择对应问题及所需模式、开始案例，待界面允许进入后执行：

```shell
python q3/v6/run_robot.py --policy v6 --config q3/v6/config.json
python q4/M32/run_robot.py --policy joint --config q4/M32/config.json
```

程序会等待回车后进入。第四问冻结入口提示按正式界面操作；模式由官方界面决定，HTTP接口不能辨别正式与演练。请遵循题目规定的时间窗口，切勿为检查材料再次开启正式测试。运行产生 `runs/时间戳/`，保存源码快照、manifest、actions.jsonl 和 summary.json。结束后在官方界面单独导出 `.jlog`；程序不能自行生成官方加密日志。

| 对照目录 | `--policy` 参数 |
|---|---|
| q3/baselines/CG | literature_cautious |
| q3/baselines/v4 | combined_v4 |
| q4/baselines/CG | cautious |
| q4/baselines/M07 | baseline |

部分冻结入口的帮助文字仍保留历史开发名称；以本表、策略源码及冻结哈希为准。不要把历史辅助模块里的 `optimize.py` 等作为本地模拟器入口。完整依赖模块原样保留，不能仅复制 `strategy.py` 运行。
