# 全局资料和准备

本目录只保存当前赛题中跨小问共享的内容，以及已经核验并允许后续小问或论文引用的正式结果。

## 可以放入本目录的内容

1. 当前题目的题面、官方附件和全题共同使用的原始数据。
2. 至少被两个小问共同使用的符号、假设、参数、代码或处理结果。
3. 已经核验并准备传递给后续小问或论文的结果。

只服务于单个小问的工作文件应留在对应小问目录。实验运行的临时结果不得直接放入 `accepted-results/`。

## 关键文件

- `assumptions.md` 保存全题共同假设。
- `symbols.md` 保存全题统一符号和单位。
- `dependencies.md` 保存各问之间的输入输出依赖。
- `decisions.md` 保存影响多个小问的重要决定。
- `accepted-results/` 保存已经核验的正式接口结果。
