# 第三问光学动作改进候选

本目录为独立研究包，默认策略 `v6`。仅有本地冻结验证，新版本尚未官方演练。第三问200秒/点目标仍未达成。

1. 安装依赖：`python -m pip install -r requirements.txt`。
2. 自检：`python run_robot.py --check`。配置默认读取同目录config.json或相邻simple-strategy/config.json；也可指定`--config`。
3. 双击run_practice.cmd，在对应问题的演练界面就绪后按程序提示开始。

默认策略参数不可通过直接修改文件后继续引用冻结成绩。每次执行保留来源快照、散列、动作和结束证书；请同时保留官方结果、案例编码与.jlog。

原版本仍在原目录。复现实验、负面结果与推导见仓库 contest/q3/models/m05-action-value/README.md。本程序不会自行识别演练或正式模式，实际测试模式由用户在模拟器界面选择。
