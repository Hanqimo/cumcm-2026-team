# 第三问多策略研究版

**尚未达到平均 200 秒/点目标。此包用于保留和复测当前候选。**

默认选择 combined_cover（负观测区域收缩 + 连续扫描点调整）。其余可选策略用于消融比较：route_guard 联合路径、region_coupled 区域收缩、continuous_cover 连续覆盖。

1. 运行 check_setup.cmd。仅检查 Python、依赖和配置，不连接模拟器。
2. 需要演练时，在官方软件选择“问题 3 演练测试”，等待接口就绪。
3. 运行 run_practice.cmd，在界面就绪后按 Enter。接口本身不能查询用户所选的演练/正式模式。
4. 完成后保存本包 runs 下自动生成的 summary.json、actions.jsonl、manifest.json 和 source_snapshot，以及模拟器案例编码、实际目标数、官方结果与 .jlog。

配置默认读取本目录 config.json，否则读取相邻 simple-strategy/config.json。不需要重新填写已有队号。依赖与旧包一致：Python 3.10、numpy 2.2.6、scipy 1.15.3。

手动选择策略：

```powershell
python run_robot.py --policy continuous_cover
python run_robot.py --policy region_coupled
python run_robot.py --policy route_guard
```

每次运行自动记录策略名称、完整参数、代码与参数文件哈希、每次动作、每次区域更新、清除证书和结束证书。网络返回不确定时停止新动作；重试复用同一请求编号。不要同时启动多个控制程序。

本地合成成绩不代表下一次官方随机案例的成绩。只有 observed_but_uncleared 为空、停止证书有效、官方总数与清除数一致，才按完整清除记录评价。总时间包含最后一次成功清除之后的排查。

原 improved-p3 包及已完成演练记录保留；本研究包位于独立目录。
