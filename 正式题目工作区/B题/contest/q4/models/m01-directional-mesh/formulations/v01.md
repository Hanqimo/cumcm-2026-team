# P4-M01-v01：未知定向源的覆盖搜索与有界定位

本文件对应可运行A01 v1.1，候选状态，非团队正式采用。本轮范围为第四问初版策略、实现、基本仿真和独立核验，不进行官方演练或正式测试。时间统计唯一来源为verification/V003-final-audit/summary.json。

## 1. 第四问改变了什么

[题目事实] B题第2页问题4及附录1：源数10–16，频道各异、位于1–20；场地圆域半径1800m；既有全向源又有定向源，数量和朝向未知。定向覆盖为朝向两侧各90°，含边界。第3页及附件2：有效接收半径1000–1500m；移动可超出场地；光学清除只受20m距离约束，不受朝向限制。

以g表示源位置、R表示其接收半径、n=(cosφ,sinφ)表示定向源朝向单位向量，τ∈{全向,定向}表示类型。位置s能够接收到未清除源当且仅当

\[
\|s-g\|\le R,\qquad [\tau=\mathrm{全向}\ \text{或}\ n^T(s-g)\ge0].
\]

示向度是s指向g的角度，不是发射朝向φ。无信号不能据此认定附近无源，或认定某源已经被清除。

| 前问成果 | 第四问处理 |
|---|---|
| Q1有界示向度半平面、多边形外包、最小包围圆 | 接收到信号时继续成立 |
| M03最近保证清除点 | 光学不受朝向限制，可直接继承 |
| Q2全向接收候选区域 | 只解决距离条件，不能承诺定向接收 |
| Q3无信号排除1000m圆盘 | 禁用；定向源可能就在旁边但背向 |
| Q3全向覆盖结束证书 | 更换为对任意朝向成立的三角网证书 |
| Q3联合路线、每次补测计费和完整尾部统计 | 继承原则；初版不自动给全部已知频道补测 |

极端例子为g=(1800,0)、n=(1,0)。严格场地内部的点均位于其发射半平面后方，仅在场内扫描没有普遍发现保证。因此外侧扫描是覆盖逻辑所需，不是数值越界；附件明确允许场外位置。

## 2. 状态、目标与更新

机器人状态为当前位置p、当前测量频道c、已发现/已清除频道集合D/C。未知频道为未被发现且未被证明不存在的频道。历史动作按频道保存位置与真实响应；只经过某点不计作检测。

时间目标为最小化完成全清所需的虚拟时间

\[
T=\frac{1}{5}\sum_k\|p_k-p_{k-1}\|+5M+S+5C_s+3C_f.
\]

其中M为检测次数，S为检测频道切换次数，C_s/C_f为成功/失败光学操作次数，/clear不改变测量频道。评价同时报告全清比例与T/N_clear；本地全清场景以真实N计算T/N，并对场景等权平均。未清完的低时间不得当作有效速度。

完整物理可行状态可写作(g,R,n,τ)的集合Ω。正观测交入接收条件和测角约束；负观测交入

\[
\|s-g\|>R\quad\text{或}\quad[\tau=\mathrm{定向},\ n^T(s-g)<0].
\]

这个析取导致非凸联合状态。初版不声称精确求解Ω，分开保存两类表示。

**可靠位置外包P。** 初始为1800m圆域的180边外接多边形；正观测交入ε=1.0051°前向角楔与1500.000001m圆盘的外接多边形；near交入5.000001m圆盘外包。保留0.005°舍入及微小数值余量。无信号仅记历史，不对P删圆盘。真实位置应始终在P中。

**规划用有限假设H。** 取P内的顶点、内部插值等位置，对每个位置采样至多3个接收半径与72个朝向，并保留全向假设。历史负观测按“超距或背向”筛选。相容样本中可接收的比例只作动作评分；它不是经过校准的真实概率，也不穷尽连续可行状态。样本为空只表示当前离散表示不足，不代表源不存在，评分回退为0.5并继续保留P。

近距离观测立即检查安全清除；半径未知与类型未知不影响光学操作。

## 3. 对任意朝向成立的发现证书

用边长L=990m的等边三角网覆盖场地，基向量为(990,0)和(495,495√3)。保留与半径1800.01m圆域相交的全部三角形，并保留其全部顶点。实现生成31个点、42个三角形，18个点在1800m圆域之外；0.01m为边界数值余量，不扩大源先验。

任取三角形顶点s₁,s₂,s₃和其中源位置g，有非负λᵢ且和为1，使g=Σλᵢsᵢ。对任意朝向n，有

\[
\sum_{i=1}^{3}\lambda_i n^T(s_i-g)=0.
\]

故三个内积不可能都严格小于0，至少一个顶点位于源的闭发射半平面。且三角形中任意两点距离不超过990m，小于R的下界1000m，所以该顶点能够接收。全向源自然也满足。

因此，如果某频道在这个三角形三个顶点都实际测得no_signal，该三角形内不存在此频道源；全部三角形满足即可排除整个场地。这里必须登记完全相同的网格坐标，不能把邻近但不同的检测点替代顶点，否则会破坏角度边界处的凸组合依据。

人工核验例：s₁=(0,0)、s₂=(990,0)、s₃=(495,857.3651497)，取重心g=(495,285.7883832)。三个顶点到g均约571.5768m。当n=(0,-1)时，前两个顶点内积为285.7884>0，第三个为−571.5768；至少一个可接收，且均在1000m以内。正式证明对任意位置和朝向成立，不依赖这个例子或朝向离散采样。

网格是初版的保守充分条件，不是必要条件或最优站点布局。未来可以用“g属于1000m内历史检测点的凸包”构造更灵活的覆盖，复用非网格观测；当前未实现这一优化。

## 4. 发现—定位—清除的闭环

1. 在原点逐频道扫描；同一位置20个频道仍分别计时。near立即清除。
2. 将仍需要扫描的网格站与已发现未清除源的区域中心作为任务点，构造固定起点、自由终点路线。最近邻初始化后最多30轮2-opt，只执行当前路线第一项，观测后重算。
3. 若任务为扫描，检测尚未排除且从未在该顶点返回负观测的未知频道；默认不附加已知频道测量。
4. 若任务为定位，先求保证清除点；若存在则执行。否则在区域中心、长轴两侧、末次有信号点向区域中心前进45%/75%的位置及侧移点中选下一点，排除与历史测点距离不足8m的位置。
5. 连续3次无信号或10次局部观测未达到清除精度，转入光学区域后备，不靠原地重测或强行删除区域结束。
6. 已发现16个不同频道后立即停止未知频道搜索，只完成已知源；清除16个后结束。若不足16个，必须所有已知源清除且每个其余频道都有全场排除证书，才能结束。

路线中的中心是服务位置近似，并未完整预测定位进入点和清除退出点；不是全局在线最优路线。执行层保持全部记录、预算和错误退出。

## 5. 下一测点的时间评分

对候选q，H中可接收比例记为p̂，围绕预测中心方位的−1°、0°、+1°三个假想读数得到平均区域半径r̂′。它们只估计测量收益，不是所有可能读数的严格最坏情况。位置中心为c，末次正观测位置为s⁺，当前包围半径为r，采用

\[
J(q)=\|p-q\|/5+6
+\hat p(\|q-c\|/5+2\hat r'/5)
+(1-\hat p)(\|q-s^+\|/5+2r/5+20).
\]

选择分数最小点。距离系数1/5来自速度，固定6s近似一次检测与换频（同频道实际仅5s，此公共项不改变同频道候选排序）；2r用于剩余定位行程近似，20s为失联处理的工程惩罚，不是题定参数或估计真值。侧移距离max(30,min(180,0.3r))也是初版参数。所有真正执行的费用按接口重新记账。

这将第三问“少走路却多测，抵消收益”的经验用于决策，但当前只实现局部评分；应通过后续消融和官方演练检验权重。没有把旧策略名称或复杂度当作有效性证据。

## 6. 清除与后备的可靠性

常规清除采用K=∩ᵥ∈vertices(P) B(v,19.5)。若K非空，选择距机器人最近的点q∈K；对凸多边形，距q的最大值在顶点取得，故真实源离q≤19.5<20m。最近点算法继承M03已核验模块。已认证清除若失败，记录冲突并停止，不能继续宣称保证。

后备光学搜索把P投影到其直径方向的坐标系，以边长26m的正方格覆盖，保留所有与P相交的方格，在每个中心尝试一次/clear。每格内点到中心≤13√2≈18.3848m，故覆盖全部P后必有一次成功，且与源发射朝向无关。实际采用最近邻次序，成功即停；失败尝试各支付3s和移动费用。它是有限覆盖搜索，不是每一次都保证成功，也不伪装成零失败清除。

完整性逻辑在题面静态物理条件、观测误差界成立、动作能正常执行且未被现实/虚拟预算截断时有效。数值几何采用浮点和外包余量，并非形式化区间算术证明。预算中止或异常必须作为未完成状态保存。

## 7. 验证与改进边界

V002用GEOS独立检查三角形并集覆盖圆域的3600边外接多边形；检查边长下界余量、随机正观测真值包含、负观测不误删区域。光学覆盖以半径19.49m的内接圆盘多边形并集核验，避免与主实现共享方格筛选逻辑。

V003逐动作按标量角度接收规则回放，重算全部时间、核对清除与覆盖证书。最终40场混合随机主审计与24场压力布局分开统计，两种策略使用同一场景。基线同样具备三角网及后备，仅使用就近几何测量并优先逐源处理；所以差异不能单独归因于朝向估计。

最大缺口是保守覆盖产生的行程和收尾，而非是否存在可终止的搜索方法。优先改进方向为任意历史测点的方向覆盖复用、自适应外围站、连续位置—朝向状态及发现新源后的任务重排。初版平均速度明显低于第三问，不能据此断言第四问时间下界，不能把它称为200秒级方案。
