# 第四问初版研究策略

默认`directional_v1`，代码版本`p4-directional-mesh-v1.1-research`。处理未知数量的全向/定向混合源，使用三角网全场覆盖、有限可见性假设选点和光学区域后备。**尚无官方演练成绩，速度仍较保守。**

独立运行目录为`D:\math modeling\正式题目工作区\B-simulator\p4-directional-research`。旧第三问目录完整保留，第四问不要运行旧第三问策略。

Python3.10已测试，依赖见requirements.txt。缺失时在本目录执行`python -m pip install -r requirements.txt`。

先做离线自检，不连接模拟器

```powershell
python run_robot.py --check --config "已有配置文件的绝对路径"
```

在模拟器选择**问题4演练测试**，待接口就绪，运行并按Enter

```powershell
python run_robot.py --policy directional_v1 --config "已有配置文件的绝对路径"
```

或双击run_practice.cmd，程序优先读取本目录config.json，然后读取相邻simple-strategy/config.json。配置仅需要原有的team_no和port，不复制或发布个人配置。也支持`--team 自己的队号 --port 2026`。接口无法查询当前是演练还是正式模式，务必由操作者选择问题4演练；本轮未代为进行任何官方测试。

对照策略为`mesh_chase_baseline`。同一演练只运行一个控制程序；需要分别用可比较案例进行对照。

每次运行在runs/日期-随机标识中保存动作、响应、源码/参数快照、散列、运行清单、结束证书和summary.json。失败光学尝试是后备区域搜索可能产生的正常费用；有“清除证书”的操作失败则属于模型冲突，会停止。若超时、手工中断或接口状态不确定，也会明确记录未完成。

报告的平均时间必须同时核对实际源总数和全清比例。请保留运行文件夹、官方案例编码、结束界面和原文件名的.jlog。不要只返回终端里的平均值。日志可能含自己的队号，分享时留意。

40场最终本地混合测试均全清，初版739.71秒/点、同场简单基线841.54秒/点；另24场压力测试全清。这些是合成场景数据，不是官方成绩。单场本地纯计算不足1秒，但真实接口往返、日志和场景差异会改变程序运行时间，无法保证与离线相同。

独立复现仿真另需Shapely2.1.2；完整命令及推导在仓库M01 README，运行官方接口本身不需要Shapely。
