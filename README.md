# CUMCM 2026 Team Workspace

2026 年全国大学生数学建模竞赛备赛协作仓库，用于沉淀公开资料、训练代码、复现记录和团队工作流。

## 目录约定

```text
docs/        公开笔记、方法说明与团队规范
documents/   历年官方试题索引与本地下载工具
notebooks/   探索性分析与可复现实验
src/         可复用的建模、求解和可视化代码
skills/      可复用的数学建模 AI 工作流 Skill
tests/       关键函数与结果一致性测试
templates/   论文、实验记录和 AI 使用记录模板
```

## 协作方式

1. 每项工作从 Issue 开始，写清目标、输入、输出和验收标准。
2. 从 `main` 创建短分支，例如 `model/baseline`、`data/cleaning`、`paper/abstract`。
3. 通过 Pull Request 合并；至少一名队友复核模型假设、代码和结果。
4. 图表和论文中的数字必须能够由仓库内代码重新生成。
5. 使用 AI 时记录工具、模型/版本、使用阶段、关键交互和人工修改。

## 基本原则

- 先建立可解释的基线，再引入复杂模型。
- 固定随机种子、数据版本和依赖版本。
- 不提交密钥、账号信息、个人身份信息或来源不明的受版权保护材料。
- 第三方资料只保存链接、引用信息和自己的笔记，遵守原始许可证。

具体提交规范见 [CONTRIBUTING.md](CONTRIBUTING.md)。
